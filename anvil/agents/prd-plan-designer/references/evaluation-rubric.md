# prd-plan-designer 평가 루브릭

PRD ↔ TDD Alignment 감사 결과를 100점 만점으로 채점한다. 에이전트가 산출하는 **매핑 표 + 정합성 검증 결과 + 지적 보고서 + 사용자 응답 텍스트**를 평가 대상으로 삼는다.

---

| # | 항목 | 배점 | 설명 |
|---|------|------|------|
| 1 | **매핑 표 완전성** | 20 | PRD §5·§6·§7·§8 모든 항목이 표에 등장하고, TDD §2~§9 모든 구현 항목도 커버됨 |
| 2 | **상태 4분류 정확도** | 20 | 매핑됨 / 누락 / 오버 스코프 / 불일치를 근거 있는 판정으로 정확히 표기 |
| 3 | **근거 라인 지목** | 15 | 매핑됨 항목이 PRD·TDD 특정 라인·섹션 인용 포함 (`prd.md:42`, `tdd.md:118` 형태) |

## AUTO FAIL 조건

다음 중 하나라도 위반하면 즉시 0점 처리:

1. **임의 문서 수정** — PRD·TDD 파일을 직접 편집 (`Edit`·`Write` 호출 발견)
2. **매핑 근거 불명확한데 "매핑됨" 표기** — PRD·TDD 라인 지목 없이 매핑됨으로 표기
3. **용어·수치 불일치 자동 결정** — 사용자 정본 판정 없이 임의로 한쪽 편들어 매핑됨 처리
4. **문서 미확보 상태에서 Phase 1 진입** — PRD 또는 TDD 없는데 매핑 표 산출 시작
5. **코드 추측 진행** — 문서에 없는 구현 내용을 코드 없이 추측해서 매핑됨 표기
6. **재호출 대상 오라우팅** — admin 모듈 대상인데 `prd-designer` 재호출 안내 (반대 케이스도 동일)

## 채점 가이드

### 항목 1. 매핑 표 완전성 (20점)

| 상태 | 점수 |
|------|------|
| PRD 4개 섹션(§5·§6·§7·§8) + TDD 8개 섹션(§2~§9) 전부 등장 | 20 |
| 1~2개 섹션 누락 (PRD 비기능 요건 또는 TDD 부록 등) | 12 |
| 3개 이상 섹션 누락 | 6 |
| PRD 또는 TDD 한쪽만 훑음 (단방향) | AUTO FAIL |

### 항목 2. 상태 4분류 정확도 (20점)

| 상태 | 점수 |
|------|------|
| 4분류 모두 사용, 각 판정에 근거 있음 | 20 |
| 오버 스코프·불일치를 누락으로 뭉뚱그림 | 12 |
| "매핑됨" 남발 (근거 부실한데 통과 표시) | 6 |
| 근거 없이 매핑됨 표기 | AUTO FAIL |

### 항목 3. 근거 라인 지목 (15점)

| 상태 | 점수 |
|------|------|
| 매핑됨·불일치 항목 모두 PRD·TDD 라인 인용 (`prd.md:N`) | 15 |
| 매핑됨만 라인 인용, 불일치는 섹션명만 | 9 |
| 라인 인용 없이 "PRD 어딘가에" 수준의 서술 | 4 |
| 근거 지목 자체 없음 | AUTO FAIL |

### 항목 4. 재호출 안내 명확성 (15점)

| 상태 | 점수 |
|------|------|
| 누락·오버스코프마다 재호출 대상 + 구체 지시 | 15 |
| 재호출 대상만 명시, 지시 문구 없음 | 9 |
| 재호출 언급만 하고 대상 스킬 미지정 | 5 |
| 재호출 안내 자체 없음 | 2 |

### 항목 5. 정본 판정 요청 품질 (10점)

| 상태 | 점수 |
|------|------|
| 불일치마다 양쪽 인용 + "어느 쪽이 정본입니까?" 명시 | 10 |
| 인용은 있으나 정본 판정 요청 문구 부재 | 6 |
| 임의로 한쪽 편들어 정합 판정 | AUTO FAIL |
| 불일치 없음 (해당 TC에 불일치 부재) | 10 (N/A 만점 처리) |

### 항목 6. 가드레일 우선 응답 (10점)

| 상태 | 점수 |
|------|------|
| 문서 부재·임의 수정 요구 시 거절 + 하드 가드레일 근거 명시 + 대안 제시 | 10 |
| 거절은 하나 근거 미명확 | 6 |
| 사용자 요구 그대로 수용 (임의 수정·매핑 결정) | AUTO FAIL |

### 항목 7. Phase 진입·중단 판단 (10점)

| 상태 | 점수 |
|------|------|
| Phase 0에서 문서 미확보 시 Phase 1 진입 금지 + 코드 검증 필요 시 명시적 중단 | 10 |
| Phase 0 통과 판정은 있으나 코드 검증 중단 판단 부재 | 6 |
| 문서 미확보 상태에서 Phase 1 진입 시도 | AUTO FAIL |

## Baseline 비교 기준

- **Baseline (에이전트 미사용)**: PRD·TDD 나란히 읽고 자연어 요약만 산출. 매핑 표·4분류·재호출 안내·정본 판정 요청 부재. 문서 자체 수정 시도 가능
- **With-Agent**: 매핑 표 3열 + 4분류 + 근거 라인 지목 + 재호출 안내 + 정본 판정 요청 + 문서 수정 금지 준수
- **합격**: With-Agent > Baseline + 20점
