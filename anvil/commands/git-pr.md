# /git-pr (스킬 별칭)

이 커맨드는 **`anvil/skills/git-pr/SKILL.md` 스킬로 승격**됐습니다.

`/git-pr` 입력 시 git-pr 스킬을 호출합니다. 스킬에서 다음을 수행:
1. 변경사항 분석 → 표준 양식으로 본문 작성
2. 신규/기존 PR 판단
3. 생성/수정 후 URL 출력

스킬 위치: `anvil/skills/git-pr/SKILL.md`

> 양식/표현 원칙/PR 본문 표준 사례는 모두 스킬 본문 참고.
