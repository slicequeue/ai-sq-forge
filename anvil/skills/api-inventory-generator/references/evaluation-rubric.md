## 평가 항목

| # | 항목 | 배점 | 설명 |
|---|------|------|------|
| 1 | **스캔 정확도** | 30 | 모든 @RestController 발견, 엔드포인트 경로·메서드 정확 |
| 2 | **인증 분류 정확도** | 25 | SecurityConstants 기반 분류가 실제와 일치 |

## AUTO FAIL 조건

1. **수작업 API 목록 직접 작성** (스크립트 미실행)
2. **스크립트 실행 실패 후 미보고**
3. **빌드 산출물(build/) 디렉토리 스캔으로 중복 엔드포인트 발생**

## 합격 기준

| 등급 | 점수 | 설명 |
|------|------|------|
| **EXCELLENT** | 90~100 | 전체 엔드포인트 정확 스캔, 인증 분류 정확 |
| **PASS** | 75~89 | 핵심 엔드포인트 스캔 OK, 경미한 미분류 |
| **FAIL** | 0~74 | 엔드포인트 누락 또는 대량 미분류 |
