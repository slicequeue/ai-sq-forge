## AUTO FAIL 조건

1. **비활성화(disable) 절차 누락** — 계획서에 disable + 확인 단계 없음
2. **운영 환경(prd) 대상 계획서 작성** — prd에서는 Chaos Monkey 미설정
3. **Bean FQCN 확인 없이 추정만으로 계획서 작성** — 코드베이스 미탐색
4. **사용자 확인 없이 계획서 파일 저장** — Step B(확인) 생략
