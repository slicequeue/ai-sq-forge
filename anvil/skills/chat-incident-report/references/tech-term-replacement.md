# 개발 용어 ↔ 비개발자 친화 표현 대체 사전

> 원칙: CS 담당자·기획자·PM 등 비개발자가 보는 메시지에서는 아래 왼쪽 용어를 쓰지 않는다. 오른쪽 표현을 쓰거나 설명을 아예 생략한다.

---

## 인증·세션 관련

| 개발 용어 | 대체 표현 / 처리 |
|---|---|
| OAuth / OAuth2 | "계정 연동" / "로그인 연동" |
| access_token / refresh_token | "로그인 유지 정보" — 대부분은 아예 언급 불필요 |
| 토큰 (token) | "로그인 정보" / 생략 |
| 토큰 만료 | "로그인이 풀린 상태" |
| 재인증 / 재로그인 | "재연결" / "다시 로그인" |
| `removeAuthorizedClient` / `disconnect*Account` 같은 메서드명 | 언급 금지. "연결이 해제된 상태" 정도로만 |
| `connection_status = CONNECTED` | "연결된 상태" / 생략 |
| `RECONNECTION_REQUIRED` | "재연결이 필요한 상태" |

## 데이터 수집·중계

| 개발 용어 | 대체 표현 / 처리 |
|---|---|
| streaming push / webhook | "자동 구독" / "자동 전송" |
| subscription | "자동 구독" |
| polling | "주기적으로 물어봄" — 대부분 언급 불필요 |
| historical-sync / bulk insert | "과거 데이터 한 번에 가져오기" |
| retry / retry batch | "재시도" |
| Cloud Task / Cloud Run | 언급 금지. "서버" 수준으로만 |
| endpoint / API | "기능" / "요청 경로" (꼭 필요할 때만) |

## DB·스토리지

| 개발 용어 | 대체 표현 / 처리 |
|---|---|
| DB row / record | "정보" / "데이터" / 생략 |
| DELETE / INSERT / UPDATE | "삭제" / "생성" / "수정" (꼭 필요할 때만. 대부분 생략) |
| `created_at` / `updated_at` | "생성 시각" / "수정 시각" 또는 생략 |
| `@CreationTimestamp` / JPA | 언급 금지 |
| 마이그레이션 | "DB 구조 변경" |

## 조사·분석

| 개발 용어 | 대체 표현 / 처리 |
|---|---|
| Cloud Logging / 로그 쿼리 | "로그 확인" / "로그" |
| RCA / Root Cause Analysis | "원인 분석" |
| repository / service / controller | 언급 금지 |
| Spring Security / JPA / Spring Boot | 언급 금지 |

## 관리 표기

| 개발 용어 | 대체 표현 / 처리 |
|---|---|
| P0 / P1 / P2 | 언급 금지. "우선순위 높음/중간/낮음" 정도가 최대 |
| Epic / 스프린트 | 언급 금지 |
| PR / merge | "코드 반영" / 생략 |
| hotfix | "긴급 수정" |
| `docs/works/...` 경로 | 언급 금지 (cc 받은 개발자가 별도 찾음) |
| 가드레일 / 가드 조건 | "사전 체크" / 생략 |

## 불확실성 표현 사전

출처 없는 단정 대신 쓰는 유보 표현:

| 금지 (출처 없는 단정) | 권장 (유보) |
|---|---|
| "외부 서비스 정책상 N일만 복구 가능" | "시스템 상황에 따라 복구가 어려울 수 있음" |
| "통상 ~분 내 수신됨" | "보통 10~60분 정도 소요됩니다" (범위 제시 + "정도") |
| "이 원인이 확실합니다" | "현재로서 가장 유력한 원인입니다. 명확한 원인은 추후 로그 확인으로 규명 예정" |
| "이 조치로 반드시 복구됩니다" | "이 조치로 복구될 가능성이 높습니다" |

## 두괄식 규칙

메시지 첫 섹션은 *상황 요약*. 배경·경위·조사 방법부터 쓰지 않는다.

| 금지 | 권장 |
|---|---|
| "어제부터 조사를 시작했는데..." | "상황: 유저 A는 ~상태, 유저 B는 ~상태" (바로 상황) |
| "기술적으로 설명드리면..." | (기술 설명 자체 최소화) |
