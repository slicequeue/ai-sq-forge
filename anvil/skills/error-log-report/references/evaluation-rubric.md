# error-log-report 평가 루브릭

구간 에러 로그 보고서 작업을 100점 만점으로 채점한다. 평가 대상은 **스킬이 산출하는 조회·집계 명령 + 판정 근거 + 보고서 본문 + 사용자 응답 텍스트**다. 실제 `gcloud` 호출은 하지 않고, 하네스가 제공하는 시뮬레이션 로그 집계 결과를 입력으로 삼는다.

|---|------|------|------|
| 1 | **Phase 0 파라미터 확정** | 15 | 프로젝트·리전·서비스·집계 기준·구간·카탈로그 6개 확정. 미확정 항목은 "가정"으로 표기 |
| 2 | **시각 변환·병기 정확도** | 15 | UTC = KST − 9h 방향 정확. 모든 시각 UTC·KST 병기 |

## AUTO FAIL 조건

다음 중 하나라도 위반하면 즉시 FAIL 처리:

1. **로그 없이 보고서 작성** — 인증 실패·권한 부족·데이터 미제공 상태에서 추정으로 보고서 본문을 채움
2. **집계 기준 미명시** — 앱 레벨(`jsonPayload.level`) vs 인프라 레벨(`severity`) 어느 쪽인지 개요에 없음
3. **시각 변환 오류 또는 단독 표기** — UTC/KST 환산 방향 오류(+9h를 −9h로 쓰거나 그 역), 또는 병기 누락
4. **로그 건수를 실패 이벤트 수로 단정** — 중복 로깅 확인 없이 로그 줄 수를 장애 건수로 보고
5. **카탈로그 대조 없이 전건 신규 판정** — 카탈로그가 제공됐는데 대조하지 않고 전부 "신규 장애"로 보고
6. **근거 링크 전무** — 유형별 딥링크·재현 쿼리가 하나도 없음
7. **사실·판단 혼재** — 추정을 사실로 단정 서술 (예: 실측 없이 "원인은 X다"로 확정)
8. **장식 기호 잔존** — 이모지·★·✅ 등 1개 이상
9. **PII 과다 노출** — 이메일·전화번호·이름 포함, 또는 필요 범위를 넘는 식별자 대량 나열
10. **후처리 실패를 데이터 유실로 보고** — `AFTER_COMMIT` 후처리 실패를 원본 데이터 유실로 서술

## 채점 가이드

### 항목 1. Phase 0 파라미터 확정 (15점)

| 상태 | 점수 |
|------|------|
| 6개 전부 확정 + 미확인 항목은 확인 방법 제시 또는 사용자 질의 | 15 |
| 5개 확정, 1개 암묵적 가정(표기 없음) | 10 |
| 집계 기준을 확인하지 않고 임의 선택 | 5 |
| 파라미터 확인 없이 바로 조회·작성 | AUTO FAIL (#2 동반) |

### 항목 2. 시각 변환·병기 정확도 (15점)

| 상태 | 점수 |
|------|------|
| 환산 정확 + 개요·타임라인·상세 전 구간 병기 | 15 |
| 환산 정확 + 일부 섹션만 병기 | 9 |
| 환산 정확 + 한쪽 타임존만 표기 | AUTO FAIL (#3) |
| 환산 방향 오류 | AUTO FAIL (#3) |

### 항목 3. 로그 건수 vs 실패 이벤트 수 분리 (15점)

| 상태 | 점수 |
|------|------|
| 중복 로깅 판별 수행 + 두 컬럼 분리 + 어느 로거 조합인지 근거 명시 | 15 |
| 두 컬럼 분리했으나 배수 근거 없음 | 9 |
| 중복 가능성만 언급하고 집계표는 단일 컬럼 | 5 |
| 로그 줄 수를 그대로 장애 건수로 보고 | AUTO FAIL (#4) |

### 항목 4. 카탈로그 대조 판정 (15점)

| 상태 | 점수 |
|------|------|
| 전건 대조 + 기존/신규 정확 분류 + 신규 유형 카탈로그 추가 제안 | 15 |
| 대조 정확하나 카탈로그 갱신 누락 | 10 |
| 일부 유형만 대조 (누락 있음) | 6 |
| 카탈로그 미존재 프로젝트에서 "최초 관측" 대신 "신규 장애 N건"으로 단정 | 4 |
| 카탈로그 제공됐는데 미대조 | AUTO FAIL (#5) |

### 항목 5. 사실·판단 분리 + 근거 링크 (15점)

| 상태 | 점수 |
|------|------|
| 유형마다 "측정값(사실)" → "판단" 분리 + 자기설명형 딥링크 | 15 |
| 분리 완료 + 링크는 있으나 텍스트가 "여기"/"링크" 형태 | 10 |
| 딥링크 대신 재현 쿼리만 제시 | 8 |
| 사실·판단 혼재 | AUTO FAIL (#7) |
| 근거 전무 | AUTO FAIL (#6) |

### 항목 6. 보고서 구조·서식 (15점)

| 상태 | 점수 |
|------|------|
| 7섹션 전부 + 파일명 규약 + 검수 스캔 실행 보고 | 15 |
| 7섹션 전부, 검수 스캔 미실행 | 10 |
| 섹션 1~2개 누락 (특히 영향 분석·근거 자료 안내) | 6 |
| 장식 기호 잔존 | AUTO FAIL (#8) |

### 항목 7. 판정 원칙 준수 (10점)

| 상태 | 점수 |
|------|------|
| 4개 원칙(후처리/마스킹/자가회복/외부의존성) 해당 케이스 전부 정확 처리 | 10 |
| 3개 정확, 1개 누락 | 7 |
| 마스킹된 원인 예외를 표면 예외로 명명 | 4 |
| 후처리 실패를 데이터 유실로 서술 | AUTO FAIL (#10) |
