# git-pr 평가 루브릭

PR 본문/생성 결과를 100점 만점으로 채점한다.

---

## 평가 항목

| # | 항목 | 배점 | 설명 |
|---|------|------|------|
| 1 | **분량·구조** | 15 | 본문 100~200줄, 코드 스니펫·SQL·mermaid 본문 사용 0건 |
| 2 | **섹션 구성 정확성** | 20 | Why/Changes/Test list 항상 포함. 측정·배포·후속은 조건부(데이터 있을 때만 추가, 없으면 생략) |
| 3 | **사람 친화 표현** | 15 | 영문 jargon 한국어 풀어쓰기, 절대 시점 명시(`D+2d` 단독 ✗), 수치 단독 노출 지양 |
| 4 | **표 활용** | 10 | Changes는 파일별 1줄 표, 측정 결과는 4지표 이내 표 (코드 없음) |
| 5 | **가드레일 준수** | 15 | `docs/` 상대 링크 0건, AI 공동작성자 표기 0건, target branch 정확(dev 기본/hotfix만 main), 한국어 본문 |
| 6 | **gh 사용 정확성** | 15 | 신규/기존 PR 자동 분기(`gh pr list` 확인), 원격 push 누락 시 `git push -u`, 기존 PR 있으면 `gh pr edit` |
| 7 | **출력 품질** | 10 | PR URL 출력, 신규/갱신 여부 한 줄 명시 |
| | **합계** | **100** | |

---

## AUTO FAIL 조건

다음 중 하나라도 위반하면 즉시 0점 처리:

1. **AI 공동작성자 표기 포함** — `Co-authored-by:` 라인에 AI/Claude 등 추가
2. **target branch 오류** — 사용자 명시 없이 `main`/`master` 대상 PR 생성 (기본 `dev`)
3. **`docs/...` 상대 링크 사용** — git 추적 제외 디렉토리 링크는 PR 페이지에서 404
4. **기존 열린 PR 무시 + 신규 생성** — 동일 head 브랜치에 PR 열려 있는데 `gh pr edit` 대신 `gh pr create`
5. **코드 스니펫·mermaid를 본문에 직접 삽입** — 양식 원칙 위반(Notion/작업 문서로 위임 안 함)
6. **본문 영어 작성** — 제목·본문은 한국어 (commit type prefix `fix:`/`feat:` 등은 OK)

---

## 합격 기준

| 등급 | 점수 |
|------|------|
| EXCELLENT | 90~100 |
| PASS | 75~89 |
| FAIL | 0~74 (또는 AUTO FAIL) |

---

## 채점 가이드

### 항목 1. 분량·구조 (15점)

| 상태 | 점수 |
|------|------|
| 100~200줄, 표 위주, 코드 스니펫 0 | 15 |
| 100줄 미만 (Why/Changes만 있고 빈약) | 8~10 |
| 200줄 초과 (코드 스니펫·장황한 설명) | 5~8 |
| 코드 스니펫·mermaid 본문 직접 삽입 | AUTO FAIL |

### 항목 2. 섹션 구성 (20점)

| 상태 | 점수 |
|------|------|
| Why/Changes/Test 모두 포함 + 조건부 섹션 정확 추가/생략 | 20 |
| 필수 섹션 누락 (Why/Changes/Test 중 1개) | -8 |
| 측정 결과 없는데 추가 / 있는데 누락 | -5 |
| 후속 작업 없는데 추가 / 있는데 누락 | -3 |

### 항목 3. 사람 친화 표현 (15점)

| 상태 | 점수 |
|------|------|
| 영문 jargon 0건, 절대 시점 명시, 의미 단위 표기 | 15 |
| jargon 1~2건 (예: `pendingAcquireTimeout` 그대로) | 10 |
| 상대 시점 단독 사용(`D+2d`) | -3 |
| 수치 단독 노출(`20s` 등) 다수 | -3 |

### 항목 4. 표 활용 (10점)

| 상태 | 점수 |
|------|------|
| Changes 표(파일별 1줄), 측정 표(4지표 이내) | 10 |
| Changes를 표 대신 bullet list로 작성 | 6 |
| 측정 결과 표에 baseline/method 등 과한 칼럼 추가 | 5 |

### 항목 5. 가드레일 (15점)

| 상태 | 점수 |
|------|------|
| docs 링크 0, AI 표기 0, target 정확, 한국어 | 15 |
| `docs/` 상대 링크 사용 | AUTO FAIL |
| AI 공동작성자 표기 | AUTO FAIL |
| target branch 오류 (사용자 명시 없이 main) | AUTO FAIL |

### 항목 6. gh 사용 정확성 (15점)

| 상태 | 점수 |
|------|------|
| 신규/기존 자동 분기, 원격 push 처리, 기존 PR이면 edit | 15 |
| 기존 PR 무시 + 신규 생성 시도 | AUTO FAIL |
| 원격 push 누락 검증 안 함 | -5 |
| `--base` 미지정 (기본값에 의존) | -3 |

### 항목 7. 출력 품질 (10점)

| 상태 | 점수 |
|------|------|
| PR URL 출력 + 신규/갱신 한 줄 명시 | 10 |
| URL만 출력, 분기 미명시 | 7 |
| URL 누락 | 3 |
