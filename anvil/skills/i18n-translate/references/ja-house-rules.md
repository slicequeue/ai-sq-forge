# 일본어 표기 — 이 저장소에서 실측으로 확인된 것

`langskill.md`(번역팀 가이드)가 정본이다. 이 문서는 가이드가 다루지 않는 부분을 **실데이터로 확인한 결과**만 담는다. 가이드와 충돌하면 가이드가 우선이고, 충돌 지점은 아래 "가이드와 어긋나는 지점"에 적어 둔다.

확인 시점: 2026-09-30
대조 대상: pasta-japan-server(일본 서비스) 저장소와 DB

## 1. 일본 서비스를 근거로 쓸 수 있는 경우와 없는 경우

### 쓸 수 있다 — UI 문구

`pasta-japan-server/shared/src/main/resources/messages/message-shared_ja_JP.properties` (약 1,450줄)

moneyball 과 **키 이름이 같은 항목이 1,176개**다. 혈당 표기가 들어간 227건 중 215건(94.7퍼센트)이 표기가 일치한다. 즉 같은 키를 찾아 일본 서비스가 뭐라고 쓰는지 볼 수 있다.

```bash
JP="${PASTA_JP_ROOT:?pasta-japan-server 체크아웃 경로를 PASTA_JP_ROOT 로 지정}"
grep -n "^<키 이름>=" $JP/shared/src/main/resources/messages/message-shared_ja_JP.properties
```

### 쓸 수 있다 — 외래어 표기 관행

일본 DB `pghd_food` 는 `name` 자체가 일본어이고 `language_names.ja` 도 같은 값이다. 약 16만 건이므로 가타카나 외래어의 표준 표기를 확인할 수 있다.

### 쓸 수 없다 — 한국 음식명

두 저장소가 완전히 다른 음식 데이터셋을 쓴다.

| moneyball `source` | 건수 | pasta-japan-server `source` | 건수 |
|---|---|---|---|
| 한국유통물류진흥원GS1 | 42,528 | calomeal v2 search | 160,425 |
| 일반 음식 추가 v1.0 | 4,488 | calomeal v2 image | 6,501 |
| 푸드샷 음식 M2 v1.0 | 1,418 | calomeal v2 barcode | 785 |
| 사용자 음식 등록 | 324 | | |

`동그랑땡`, `꽈배기`, `어복쟁반` 같은 한국 고유 음식은 일본 DB 에 없다. 1:1 대조로 답을 가져올 수 없으므로 일반 일본어 표기법으로 판단해야 한다.

## 2. 혈당 표기 — グルコース値 / 血糖値

**혼용이 아니라 의도적 구분이다. 한쪽으로 통일하지 않는다.**

일본 CGM 제품은 간질액 포도당과 채혈 혈당을 구분해 쓰며, 규제 표현과 얽힌다.

| 표기 | 쓰는 자리 |
|---|---|
| `グルコース値` | CGM 이 측정한 값 자체, 측정값 그래프, 센서 보정, 측정 진행 상태 |
| `血糖値` | 생리학적 개념 설명, 건강 효과 서술, 혈당 스파이크, **CGM 데이터가 없는 상태의 안내**, 데이터 유형명, 예측 결과 |

일본 서비스가 `血糖` 을 쓰는 31건이 위 맥락에 모여 있다. 특히 `home.glucose.card.cgm_inactive` / `manual_only` / `no_data` 가 모두 `血糖` 인 점이 기준을 뒷받침한다. CGM 측정값이 존재하지 않는 맥락에서만 `血糖` 을 쓴다.

한 문장 안에서 역할을 나눈 사례도 있다.

```
平均グルコース値グラフをよく観察し、骨格筋量の減少が血糖値に影響を与えていないか確認してください。
      측정값과 그래프                              생리학적 상태
```

신규 번역에서 판단이 서지 않으면, 같은 번들의 인접 키가 어느 쪽을 쓰는지 보고 맞춘다. 같은 화면에서 표기가 섞이는 것이 한쪽으로 잘못 통일하는 것보다 낫다는 판단은 하지 않는다 — 맥락으로 갈린다.

상세 근거는 `docs/i18n/analysis/일본어 혈당 표기 규칙.md` 와 지라 VCBE-175 에 있다.

## 3. 외래어 표기 — 장음·촉음을 빠뜨리지 않는다

moneyball 데이터에서 장음·촉음이 빠진 표기가 다수 확인됐다. 일본 DB 실데이터 기준이다.

| 잘못 | 올바름 | 유형 |
|---|---|---|
| `サイダ` | `サイダー` | 장음 |
| `ブロッコリ` | `ブロッコリー` | 장음 |
| `アイスティ` | `アイスティー` | 장음 |
| `バブルティ` | `バブルティー` | 장음 |
| `スターフルト` | `スターフルーツ` | 장음 |
| `ピカンタルト` | `ピーカンタルト` | 장음 |
| `ダクアズ` | `ダックワーズ` | 촉음 |
| `シュニチェル` | `シュニッツェル` | 촉음 |
| `フリータータ` | `フリッタータ` | 촉음 |
| `ゴロケ` | `コロッケ` | 촉음·청탁 |
| `ステュ` | `シチュー` | 관용 표기 |
| `パエヤ` | `パエリア` | 관용 표기 |
| `カルジョネ` | `カルツォーネ` | 관용 표기 |

가타카나 외래어를 쓸 때는 **일본 DB 에 같은 단어가 있는지 먼저 확인한다.** 있으면 그 표기를 따른다.

## 4. 일본 요리·제품은 음역하지 않는다

원래 일본어인 것을 가타카나로 음역하면 안 된다.

| 잘못 | 올바름 |
|---|---|
| `チャワンムシ` | `茶碗蒸し` |
| `ドジマロール` | `堂島ロール` |
| `ラクキョ` | `らっきょう` |

`らっきょう` 처럼 히라가나가 관례인 것도 있다.

## 5. 한국 음식명 — 기계번역이 고유명사를 쪼갠다

실제로 발생한 오역이다. 이름을 의미 단위로 분해해 번역한 흔적이다.

| 한국어 | 잘못된 값 | 분해된 방식 |
|---|---|---|
| 쌍화차 | `ダブルデッキバス` | 쌍(double) + 화차(freight car) |
| 신선로 | `フレッシュロード` | 신선(fresh) + 로(road) |
| 규카츠 | `キツネカツ` | 규를 여우로 읽음 |
| 차조밥 | `チャーハン` | 차조를 볶음으로 읽음 |
| 빨미까레 | `カレー` | 까레를 카레로 읽음 |

한국 고유 음식을 번역할 때는 **이름 전체가 하나의 고유명사인지 먼저 판단한다.** 고유명사면 음역하거나 재료·조리법으로 풀어 쓰고, 부분 번역하지 않는다.

같은 이유로 아래 유형도 반복 확인됐다.

- 재료가 서로 뒤바뀜: `표고버섯 ↔ 양송이버섯`, `멍게 ↔ 해삼`
- 상위어로 뭉갬: `깍두기 → キムチ`, `배추전 → キムチチヂミ`, `김국 → キムチ`
- 비슷한 과일로 치환: `참외 → スイカ`, `산딸기 → イチゴ`, `청포도 → ブルーベリー`, `건포도 → ブドウ`

신규 번역 후 **원문과 뜻이 같은 것을 가리키는지** 한 번 더 확인한다. 특히 재료명·과일명은 유사어로 치환되기 쉽다.
