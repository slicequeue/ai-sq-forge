# java-business-logic-reviewer 평가 루브릭

백엔드 Java Spring Boot 코드에 대한 **비즈니스 로직·요건 준수 리뷰 결과 리포트**를 100점 만점으로 채점한다. 스킬이 산출하는 리뷰 리포트 마크다운(불변식 위반·미구현·사각지대·부분 매핑·매핑됨 5분류 + 통계)을 평가 대상으로 삼는다.

---

| # | 항목 | 배점 | 설명 |
|---|------|------|------|
| 1 | **Phase 0 문서 확보** | 10 | PRD·TDD 위치를 명시적으로 확인. 없을 때 사용자에게 요청. BIZ-HG-1 |
| 2 | **PRD 수용 기준 추출 완전성** | 15 | 항목 번호 + 원문 인용으로 checklist 산출. 모호 문구는 사용자 확인 |
| 3 | **TDD 시그니처 추출** | 10 | 계층·엔드포인트·엔티티·예외 클래스·HTTP status 매핑 |
| 4 | **도메인 불변식 격리** | 15 | Phase 1.3 별도 리스트. "반드시/절대" 문장 추출 완결성. BIZ-HG-4 대비 준비 |

## AUTO FAIL 조건

다음 중 하나라도 위반하면 즉시 0점 처리:

1. **BIZ-HG-1 위반** — Phase 0 문서 확보 없이 리뷰 진행 (사용자 요청 확인 절차 skip) — 직접 발동 TC: **TC-4**
2. **BIZ-HG-2 위반** — 요건 문구 모호 시 사용자 확인 없이 임의 해석·확장 — 직접 발동 TC: **TC-5**
3. **BIZ-HG-3 위반** — 매핑됨 판정에 파일:라인 근거 부재 — 직접 발동 TC: **TC-7 (v0.2 신규)**
4. **BIZ-HG-4 위반** — 도메인 불변식 위반 발견을 리포트 최상단에 배치하지 않음 (숨김 또는 후순위) — 직접 발동 TC: **TC-6 (v0.2 신규, #633 재현)**
5. **BIZ-HG-5 위반** — 코드를 Edit/Write로 자의적 수정 시도
6. **스코프 침범** — 보안·성능·아키텍처 관점을 임의로 다룸 (각 리뷰어에 위임 안내 대신) — 직접 발동 TC: **TC-8 (v0.2 신규)**
7. **층위 침범** — 문서↔문서(prd-plan-designer 스코프) 케이스를 임의 매핑 — 직접 발동 TC: **TC-9 (v0.2 신규)**
8. **판정 없는 리뷰** — 5분류 판정 아이콘 없이 요약만 산출

## 채점 가이드

### 항목 1. Phase 0 문서 확보 (10점)

| 상태 | 점수 |
|------|------|
| PRD·TDD 파일 위치 명시적 확인 + 없으면 사용자 요청 | 10 |
| 위치 확인은 했으나 문서 부재를 그냥 진행 (안내 없이) | 4 |
| Phase 0 자체 skip | AUTO FAIL |

### 항목 2. PRD 수용 기준 추출 (15점)

| 상태 | 점수 |
|------|------|
| 수용 기준 항목 번호 + 원문 인용 + 모호 문구는 사용자 확인 요청 | 15 |
| 항목 번호는 있으나 원문 인용 없음 | 10 |
| 모호 문구를 임의 해석 | AUTO FAIL |
| PRD 수용 기준 섹션 자체 skip | 3 |

### 항목 3. TDD 시그니처 추출 (10점)

| 상태 | 점수 |
|------|------|
| 계층·엔드포인트·엔티티·예외·HTTP status 5종 모두 매핑 | 10 |
| 3~4종 매핑 (일부 누락) | 6 |
| 엔드포인트만 | 3 |
| TDD 확인 자체 skip | 1 |

### 항목 4. 도메인 불변식 격리 (15점)

| 상태 | 점수 |
|------|------|
| "반드시/절대/오직/never/always" 문장을 별도 리스트에 격리 + 각 불변식 코드 대응 위치 확인 | 15 |
| 격리는 했으나 코드 대응 없음 | 10 |
| 격리 없이 본문 검토에 섞음 | 6 |
| 불변식 개념 자체 무시 | AUTO FAIL (BIZ-HG-4 대비 실패) |

### 항목 5. 코드 매칭 근거 (15점)

| 상태 | 점수 |
|------|------|
| 매 매핑 판정마다 파일:라인 명시 + Controller→Service→Domain 계층 추적 | 15 |
| 파일 경로는 있으나 라인 번호 누락 | 10 |
| 근거 없이 "매핑됨" 판정 | AUTO FAIL |

### 항목 6. 5분류 판정 정확도 (15점)

| 상태 | 점수 |
|------|------|
| 매핑됨·부분·미구현·사각지대·불변식 위반 아이콘 정확 + 유형 코드(BIZ-*) 명시 | 15 |
| 🟠 불변식 위반 검출 시 실전 사고 인용(#633 등) + 수정안 3건 이상 | +2 보너스 (최대 15 유지) |
| 5분류 중 1개 누락 (예: 사각지대 미검출) | 11 |
| 3분류 이하 (매핑됨/미구현/기타만) | 6 |
| 판정 없음 | AUTO FAIL |

**v0.2 강화 (2026-07-29)**: 🟠 불변식 위반 판정은 실전 사고 유발 위험이 큰 최우선 감지 항목. TC-6(#633 재현)에서 파일:라인 근거 2건 이상 + 수정안 3건(도메인 검증 + 예외 변환 + REQUIRES_NEW 격리) 요구.

### 항목 7. 불변식 위반 최우선 배치 (10점)

| 상태 | 점수 |
|------|------|
| 불변식 위반 발견 시 리포트 최상단 + 등급 AUTO FAIL/Critical + 실전 사고 인용 | 10 |
| 최상단 배치 + AUTO FAIL 등급, 사고 인용 없음 | 8 |
| 불변식 위반 발견은 있으나 하단 배치 | AUTO FAIL (BIZ-HG-4) |
| 불변식 위반 없음 (요건 검증 결과 없음) → "없음" 명시 통과 | 10 |

### 항목 8. 범위 준수 & 이관 안내 (10점)

| 상태 | 점수 |
|------|------|
| 보안·성능·아키텍처·공통 룰 발견 시 각 리뷰어 위임 안내 명시 + java-composite-reviewer 조합 호출 권장 | 10 |
| 위임 안내는 있으나 정본 위치·조합 호출 문구 부실 | 7 |
| 스코프 밖 항목 임의 보고 (스코프 침범) | AUTO FAIL |
| 문서↔문서 케이스 임의 매핑 (층위 침범) | AUTO FAIL (v0.2 신규) |
| 스코프 밖 항목 무시 (안내 없이) | 6 |

**v0.2 강화 (2026-07-29)**:
- TC-8: 보안·성능 발견을 BIZ 본문 판정으로 포함하지 말고 위임 안내만
- TC-9: 문서↔문서(PRD↔TDD) 요청 시 prd-plan-designer 재호출 안내 필수 (임의 매핑 강행 시 층위 침범 AUTO FAIL)
