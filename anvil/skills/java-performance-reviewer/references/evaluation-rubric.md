# java-performance-reviewer 평가 루브릭

성능 관점 코드 리뷰 산출물을 100점 만점으로 채점한다. 스킬이 산출하는 **리뷰 리포트(AUTO FAIL·필수 수정·권장 개선 3분류) + 자기 검증 응답**을 평가 대상으로 삼는다.

## AUTO FAIL 조건

다음 중 하나라도 위반하면 즉시 0점 처리:

1. **G-1 놓침** — 변경 파일에 `@OneToMany`/`@ManyToMany` EAGER 있는데 AUTO FAIL 미검출
2. **G-2 놓침** — for/stream 안 Repository 조회 있는데 AUTO FAIL 미검출
3. **G-3 놓침** — WebClient timeout 미설정인데 AUTO FAIL 미검출
4. **G-4 놓침** — Retry 필터에 4xx 포함되어 있는데 AUTO FAIL 미검출
5. **G-5 놓침** — 싱글톤 mutable instance field 있는데 AUTO FAIL 미검출
6. **관점 침범** — 아키텍처·보안·컨벤션 지적을 이 스킬 리포트에 넣음
7. **코드 변경 실행** — 스킬이 파일 수정·커밋·push 실행 (읽기 전용 위반)
8. **사용자 요구 그대로 수용** — AUTO FAIL 완화 요구를 근거 없이 수용

## 채점 가이드

### 항목 1. 하드 가드레일 탐지 정확도 (25점)

| 상태 | 점수 |
|------|------|
| G-1~G-5 5개 모두 정확히 검출 + 이유·권장 수정 명시 | 25 |
| 5개 중 4개만 검출 (1개 놓침) | AUTO FAIL |
| False positive 1건 (실제로는 위반 아닌데 AUTO FAIL 판정) | 15 |

### 항목 2. N+1·JPA 검사 품질 (15점)

| 상태 | 점수 |
|------|------|
| fetch 전략·반복문 조회·EXPLAIN·인덱스 4항목 모두 검토 + 개선 방향 | 15 |
| 3항목만 검토 (1개 누락) | 10 |
| 2항목 이하 | 5 |

### 항목 3. 캐시 계층 검사 품질 (15점)

| 상태 | 점수 |
|------|------|
| 6원칙(3층 폴백·write-through 시점·전체 재작성·발행 실패 흡수·워밍업·refresh 로그) 모두 검토 | 15 |
| 4~5원칙 검토 | 10 |
| 3원칙 이하 | 5 |
| 캐시 없음 (해당 없음) | 만점 처리 |

### 항목 4. 트랜잭션·비동기 검사 (10점)

| 상태 | 점수 |
|------|------|
| propagation·트랜잭션 외부 호출·@Async executor·HikariCP 4항목 검토 | 10 |
| 2~3항목 검토 | 6 |
| 1항목 이하 | 3 |

### 항목 5. 리소스·로깅 스팸 검사 (10점)

| 상태 | 점수 |
|------|------|
| try-with-resources·페이로드 요약·반복문 로그 3항목 검토 | 10 |
| 2항목 검토 | 6 |
| 1항목 이하 | 3 |

### 항목 6. 관점 침범 회피 (10점)

| 상태 | 점수 |
|------|------|
| 아키텍처·보안·컨벤션 지적 발견 시 라우팅 안내만, 리포트에서 제외 | 10 |
| 라우팅 안내는 있으나 리포트에도 포함 | 5 |
| 관점 침범 지적 다수 포함 | AUTO FAIL |
