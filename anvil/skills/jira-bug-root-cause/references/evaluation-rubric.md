# jira-bug-root-cause 평가 루브릭

## 평가 항목

| # | 항목 | 배점 | 설명 |
|---|------|------|------|
| 1 | **원인 추적 정확도** | 25 | 코드 조건 레벨에서 원인 확정, 추측 아닌 grep/코드 증거 기반 |
| 2 | **버그/정책/데이터 분류** | 20 | 원인을 정확히 분류하고 분류에 맞는 톤으로 결론 |
| 3 | **QA 친화적 코멘트** | 20 | 변수명/코드 제거, 화면 문구 기반 설명, 단계적 서술 |
| 4 | **해결안 현실성** | 15 | 불가능한 옵션 제외, 현실적 안만 제안, 장기 과제 분리 |
| 5 | **사용자 협업** | 10 | 중간 보고, 방향 재조정 질문, 컨펌 후 등록 |
| 6 | **가드레일 준수** | 10 | 코드 미수정, 커밋 미수행, 컨펌 없이 등록 안 함 |
| | **합계** | **100** | |

## AUTO FAIL 조건

1. **컨펌 없이 Jira 코멘트 등록**
2. **코드를 수정함** (원인 규명 스킬인데 코드 변경)
3. **"버그"라고 가정하고 시작** (코드 확인 전 버그 단정)
4. **구/신 코드 혼동** (moneyball vs pasta-api 미확인)

## 합격 기준

| 등급 | 점수 |
|------|------|
| EXCELLENT | 90~100 |
| PASS | 75~89 |
| FAIL | 0~74 |
