# pr-feedback-resolver 평가 루브릭

## 평가 항목

| # | 항목 | 배점 | 설명 |
|---|------|------|------|
| 1 | **피드백 수집 완전성** | 20 | 이슈 코멘트 + 리뷰 코멘트 + CodeRabbit 전수 수집 |
| 2 | **CodeRabbit 식별** | 10 | CodeRabbit 코멘트를 별도 식별하고 우선 처리 |
| 3 | **수정 계획 품질** | 15 | 파일:라인, 출처, 우선순위 분류가 정확 |
| 4 | **수정 정확도** | 20 | 피드백 요구사항에 맞게 코드 수정, 규칙 위반 미발생 |
| 5 | **순서 준수** | 20 | 수정 → 커밋(/git-commit) → push → 답글 순서 |
| 6 | **가드레일 준수** | 15 | push 전 답글 금지, 마이그레이션 보호, stash 금지. (v1.10) 종료 보고 share-lint `[확인]` 1건당 -2, 바꾼 단계 표기 사유 미안내 -3 |
| | **합계** | **100** | |

---

## AUTO FAIL 조건

1. **push 전에 답글을 작성함** (CodeRabbit resolved 처리 불가)
2. **`/git-commit` 스킬 미사용** (임의 형식 커밋)
3. **기존 obesity 마이그레이션 파일 수정/삭제**
4. **git stash 사용**
5. **(v1.7) review-lint 미실행 또는 위반이 남은 채 push** (사용자가 생략을 요청해도 동일)
6. **(v1.8) dev 반영을 위해 force push** (merge 로 반영해야 함)
7. **(v1.10) 종료 보고가 share-lint SW-1·SW-6 위반** — 첫 줄에 결론·반영 단계 없음, "없음"·"해당 없음" 줄. 응답 원문의 보고 부분을 파일로 저장해 `python3 -B forge/common/share-lint.py 파일` 로 판정
8. **(v1.10) 확인 근거 없이 `운영 반영`·`배포 완료` 기재** (종료 보고·답글 모두, 사용자가 요청해도 동일 — 카탈로그 O-3)
