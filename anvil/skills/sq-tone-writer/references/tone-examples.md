## 매체별 변환 예시

### 원본 요청: "쿠폰 일괄 발급 API 완성, 테스트 통과"

#### 슬랙 (팀 동료)
```
쿠폰 일괄 발급 API 완성. 테스트 전부 통과.
PR 올렸으니 확인 부탁.
```

#### 슬랙 (리더)
```
쿠폰 일괄 발급 API 구현 완료했습니다.
단위 테스트 전체 통과, PR 올렸습니다. 확인 부탁드립니다.
```

#### PR 본문
```
## 요약
- 쿠폰 일괄 발급 API 구현 (Controller, Service, Repository)
- 단위 테스트 작성 (Application, Infrastructure 계층)

## 변경 파일
| 계층 | 파일 | 내용 |
|------|------|------|
| Web | CouponBulkIssueController | 발급 요청 엔드포인트 |
| App | CouponBulkIssueService | 발급 로직 |
| Infra | CouponCodeJpaRepository | 일괄 저장 |

## 테스트
`./gradlew :pasta-api:test --tests *CouponBulk*` 전체 통과
```
