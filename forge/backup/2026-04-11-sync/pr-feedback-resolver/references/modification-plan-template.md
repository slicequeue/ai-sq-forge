# 수정 계획 문서 템플릿

아래 형식으로 `docs/pr-modification-plan-{PR번호}.md`를 생성한다.

---

```markdown
# PR #{번호} 수정 계획

## PR 정보

| 항목 | 값 |
|------|-----|
| PR 번호 | #{번호} |
| 제목 | {제목} |
| URL | {URL} |
| 브랜치 | {브랜치명} |
| 작성일 | {날짜} |

---

## 수정 요청 요약

| 출처 | 건수 | 우선순위 |
|------|------|---------|
| CodeRabbit | {N}건 | 높음 |
| 리뷰어 수정 요청 | {N}건 | 높음 |
| 리뷰어 제안 | {N}건 | 중간 |
| 질문/논의 | {N}건 | 낮음 (답변만) |

---

## 수정 작업 계획 (우선순위)

### 높음 (즉시 수정)

- [ ] **{파일}:{라인}** — {수정 내용}
  - 출처: {CodeRabbit / 리뷰어명}
  - 원문: "{코멘트 원문 요약}"

- [ ] **{파일}:{라인}** — {수정 내용}
  - 출처: {출처}
  - 원문: "{원문 요약}"

### 중간 (가능하면 반영)

- [ ] **{파일}:{라인}** — {수정 내용}
  - 출처: {출처}
  - 원문: "{원문 요약}"

### 낮음 (답변만)

- [ ] {질문/논의 내용 요약} → 답변: "{답변 내용}"

---

## 수정 완료 후 체크리스트

- [ ] 모든 높음 항목 수정 완료
- [ ] /git-commit 스킬로 커밋
- [ ] git push 완료
- [ ] PR 코멘트에 답글 완료
- [ ] 수정이 기존 테스트를 깨뜨리지 않는지 확인
```
