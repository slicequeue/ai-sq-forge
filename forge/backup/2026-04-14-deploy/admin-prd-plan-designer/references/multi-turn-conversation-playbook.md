# Multi-turn Conversation Playbook

## 목표
- 사용자와 대화를 통해 요구사항을 점진적으로 정밀화한다.
- 애매한 요청을 바로 문서화하지 않고 합의 단계를 거친다.

## 턴 운영 규칙
1. 한 턴 질문은 최대 3개
2. 의사결정에 필요한 질문만 수행
3. 턴 종료 시 결정/미결/다음질문을 요약
4. 미결사항은 Open Questions로 전환

## 질문 프레임
- 목적: 이 기능의 완료 정의는 무엇인가?
- 권한: 어떤 관리자 역할이 사용할 수 있는가?
- 흐름: 진입/조회/수정/완료/실패는 어떻게 되는가?
- 기록: 어떤 액션을 admin history에 남겨야 하는가?
- 산출물: PRD, TDD, HYBRID 중 무엇이 필요한가?
