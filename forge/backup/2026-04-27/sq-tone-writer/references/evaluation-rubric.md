# sq-tone-writer 평가 루브릭

## 평가 항목

| # | 항목 | 배점 | 설명 |
|---|------|------|------|
| 1 | **AI 표현 제거** | 25 | "~것 같습니다", "감사하겠습니다" 등 AI 냄새 0건 |
| 2 | **간결성** | 25 | 30자 초과 문장 비율 10% 이하, 불필요한 접속사/수식어 없음 |
| 3 | **톤 자연스러움** | 20 | 구어체 활용, 사용자가 직접 쓴 것 같은 느낌 |
| 4 | **매체 적합성** | 15 | 슬랙/PR/문서 등 매체에 맞는 구조와 길이 |
| 5 | **핵심 전달력** | 15 | 두괄식, 첫 문장에 결론, 표/리스트 활용 |
| | **합계** | **100** | |

## AUTO FAIL 조건

1. **"~하는 것이 좋을 것 같습니다" 류 표현 사용** (AI 톤)
2. **장황한 서론** ("안녕하세요, 다름이 아니라...")
3. **이모지 무단 사용** (사용자 미요청 시)
4. **매체/수신자 미확인 후 작성**

## 합격 기준

| 등급 | 점수 |
|------|------|
| EXCELLENT | 90~100 |
| PASS | 75~89 |
| FAIL | 0~74 |
