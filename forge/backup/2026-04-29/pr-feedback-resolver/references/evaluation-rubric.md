# pr-feedback-resolver 평가 루브릭

---

## 평가 항목

| # | 항목 | 배점 | 설명 |
|---|------|------|------|
| 1 | **피드백 수집 완전성** | 20 | 이슈 코멘트 + 리뷰 코멘트 + CodeRabbit 전수 수집 |
| 2 | **CodeRabbit 식별** | 10 | CodeRabbit 코멘트를 별도 식별하고 우선 처리 |
| 3 | **수정 계획 품질** | 15 | 파일:라인, 출처, 우선순위 분류가 정확 |
| 4 | **수정 정확도** | 20 | 피드백 요구사항에 맞게 코드 수정, 규칙 위반 미발생 |
| 5 | **순서 준수** | 20 | 수정 → 커밋(/git-commit) → push → 답글 순서 |
| 6 | **가드레일 준수** | 15 | push 전 답글 금지, 마이그레이션 보호, stash 금지 |
| | **합계** | **100** | |

---

## AUTO FAIL 조건

1. **push 전에 답글을 작성함** (CodeRabbit resolved 처리 불가)
2. **`/git-commit` 스킬 미사용** (임의 형식 커밋)
3. **기존 obesity 마이그레이션 파일 수정/삭제**
4. **git stash 사용**

---

## 합격 기준

| 등급 | 점수 |
|------|------|
| EXCELLENT | 90~100 |
| PASS | 75~89 |
| FAIL | 0~74 |
