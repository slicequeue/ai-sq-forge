# Command Blueprint

커맨드는 슬래시(`/xxx`)로 트리거되는 단위 작업이다. 스킬보다 가볍고, 특정 작업을 빠르게 실행하는 데 최적화되어 있다.

## 디렉토리 구조

```
anvil/commands/{command-name}/
├── COMMAND.md              # 커맨드 정의
└── references/             # 선택
```

## COMMAND.md 템플릿

```markdown
---
name: {command-name}
description: "{한 줄 설명}"
trigger: "/{slash-command}"
args: "{선택적 인자 설명}"
---

# /{command-name}

## 용도
{이 커맨드가 해결하는 문제 한 줄}

## 인자

| 인자 | 필수 | 설명 | 기본값 |
|------|------|------|--------|
| ... | ... | ... | ... |

## 실행 로직

1. {단계}
2. {단계}

## 출력 형식

{예상 출력}

## 가드레일

- {제한 사항}
```

## 설계 원칙

- **한 가지 일만** — 커맨드 하나가 여러 일을 하면 스킬이나 스킬체인으로 승격
- **빠른 실행** — 대화형 Q&A 없이 즉시 실행되어야 함
- **멱등성 권장** — 같은 인자로 여러 번 실행해도 안전해야 함
