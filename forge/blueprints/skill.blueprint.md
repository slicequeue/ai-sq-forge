# Skill Blueprint

스킬은 Claude Code에서 `SKILL.md` 파일로 인식되는 독립 작업 단위다.

## 디렉토리 구조

```
anvil/skills/{skill-name}/
├── SKILL.md              # 메인 스킬 정의 (역할, 지침, 가드레일)
└── references/           # 상세 패턴/예시 (SKILL.md가 길어질 때 분리)
    ├── {topic-1}.md
    └── {topic-2}.md
```

## SKILL.md 템플릿

```markdown
---
name: {skill-name}
description: "{한 줄 설명. 트리거 키워드 포함. 예: 'PRD/TDD 문서 작성 전문가. PRD 작성, TDD 설계, 기술 문서 요청 시 사용.'}"
---

# {skill-name} - {짧은 제목}

> (선택) 공유 컨텍스트 참조 경로

---
```

## 설계 원칙

1. **SKILL.md는 400줄 이내** 유지 — 초과 시 references/로 분리
2. **description은 트리거 키워드 포함** — Claude Code가 스킬을 자동 매칭하는 기준
3. **하드 가드레일은 본문에 직접 기술** — references로 분리하지 않음
4. **자기 검증 체크리스트 필수** — 스킬이 스스로 품질을 검증하는 장치
5. **references/ 내 파일은 목차(TOC) 포함** — 빠른 탐색 지원

## References 분리 기준

| 상황 | 처리 |
|------|------|
| 규칙이 표 3개 이상 or 코드 예시 포함 | → references/로 분리 |
| 가드레일 (hard) | → SKILL.md 본문 유지 |
| 선택 매트릭스, 패턴별 코드 예시 | → references/로 분리 |
| Phase 0 사전 확인, 실행 순서 | → SKILL.md 본문 유지 |
