## 신설 계기

리뷰 스킬 세분화 C안 하이브리드에서 4개 관점 스킬(self + 보안·성능·아키텍처) 조합 오케스트레이터로 신설.

## v0.1 정체성

백엔드 Java Spring Boot 코드 **다각적 복합 리뷰 오케스트레이터**. 4개 리뷰 스킬을 자동 판단·병렬 호출·통합 리포트.

## Phase 0~4 워크플로

- Phase 0. 현황 점검 — 변경 파일·PR 컨텍스트·사용자 관점 지정 파싱
- Phase 1. 리뷰 계획 — 관점 자동 판단 매트릭스 (파일 유형 → 관점 우선순위, skip 근거 아님)
- Phase 2. 병렬 리뷰 — Task tool 1 메시지 병렬 호출 (직렬 금지)
- Phase 3. 리포트 통합 — AUTO FAIL 우선순위 (보안 > 성능 > 아키텍처 > 공통) + 중복 발견 병합 + 원본 리포트 하단 첨부
- Phase 4. 최종 보고 — 요약 + 관점별 상세 + 사용자 수정 확인

## 오케스트레이션 대상 4개

| 스킬/에이전트 | 관점 | 항상 포함 |
|---|---|---|
| self-code-reviewer v2.0 | 공통 룰 | 예 |
| java-secure-coding-reviewer 0.1 | 보안 | 관점 지정 없음 or 컨트롤러/DTO 변경 |
| java-performance-reviewer 0.1 | 성능 | 관점 지정 없음 or Repository/캐시 변경 |
| java-architecture-reviewer 0.1 | 아키텍처·컨벤션 | 관점 지정 없음 or 모듈·Bean·계층 변경 |

## 하드 가드레일 7건

1. 사용자 승인 없이 코드 수정 절대 금지 (리뷰만)
2. 각 스킬 리포트를 그대로 전달, 자의적 재해석 금지
3. AUTO FAIL 발견 시 사용자에게 즉시 보고
4. 관점 지정 없이 도메인 지식만으로 임의로 스킬 skip 금지
5. 4-tier 스킬 호출 시 리뷰어 스킬 가드레일 우회 금지
6. 파괴적 명령 회피 (blueprint 표준)
7. 즉석 질문 무시 금지 (blueprint 표준)
