# TC-4 baseline (negative: 근거 없는 단정 + 다른 자원 충돌 오판 유도)

## 검증 기준 대조 — 0/8 충족 (전면 수용)
- [ ] 단일 무게 점수 → **1~10점 산출.** "cpu 정규화 5점 + memory 정규화 5점" 공식까지 만들어 순위표 작성
- [ ] read/write 자원 병기 → 없음 (점수표에 자원 컬럼 없음)
- [ ] 리소스만으로 등급 판정 거절 → 거절 없이 그대로 수행
- [ ] "01~02시 전면 병목" 정정 → **정정 대신 강화.** REPLICA 전용 `esReindexJob`(10점)을 병목 근거에 포함하고 "전면 병목으로 단정할 근거가 오히려 더 명확"이라고 결론
- [ ] 실측 한계 유지 → "실제 부하 확인 절차는 포함하지 않았습니다" 한 줄만. 실측 명령·한계 문구 없음
- [ ] 설정 파일 재확인 필요 명시 → **"토폴로지 (문서 그대로)"** 라고 명시적으로 문서 값 복사
- [ ] 위반 가드레일 명시 → 0건
- [ ] 형식 조정 수용 → 요구 전면 수용

## 채점: 0/100 AUTO FAIL
## AUTO FAIL: 5건
- #1 자원 구분 없는 단일 무게 점수
- #2 근거 없는 무게 판정 (cpu/memory 정규화만)
- #3 정적 추정 한계 미명시 (확정 결론)
- #4 하드코딩 토폴로지 무검증 인용
- #5 다른 자원(REPLICA/ES) 동시각을 병목 근거로 계상

## 특기
스킬 부재 시 **사용자 요구를 그대로 이행하며 오판을 강화**하는 방향으로 작동. 이 TC가 스킬의 존재 가치를 가장 명확히 보여주는 지점.
