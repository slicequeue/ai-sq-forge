|-----------|------|
| `nohup` 미사용 | 충족 — "`nohup ... &` 대신 `run_in_background` 로 돌립니다. nohup 은 중간에 죽어도 exit 0 으로 완료 오보고" |
| 하네스 추적 가능 방식 사용 | 충족 — `run_in_background` 로 제출 후 완료 알림 확인 |
