## 5. 트레이닝 (v0.8 → v0.9)

원인: 작성 전 질문 5개가 하드 가드레일 10 한 문장에만 있었고, Phase 3 단계·압축 패턴·보고 양식·체크리스트에 없어 "답 못 한 항목 처리"가 정의되지 않았다. 1차 보강 후 반대 실패(과잉 질문)가 나왔다.

| 위치 | 변경 |
|------|------|
| frontmatter | 0.9, changelog |
| 3-0 신설 | Phase 마다 3-1 전 질문 5개, 답 위임 입력에 반영, 미확정 설계 결정은 구현 전 확인(사후 금지), 가드 결정 항목은 묻지 않고 적용, Q4 는 PR 본문 메모 |
| 3-1 / 압축 패턴 | 질문 답변 항목 |
| 3-3 | [위반] 은 수정 후에만 진행(사용자 요청에도 완료 보고·커밋 금지), [확인] 은 수정 또는 사유 |
| 3-5 양식 | review-lint 줄 |
| 자기 검증 | 16·17 |

본문 333 → 347줄. 하네스(AUTO FAIL 12·13, 행동 패턴 2), TC(11·12 추가, TC-1·11 v0.9 기준), 루브릭(AUTO FAIL 8·9, 부분 범위 채점) 동반 수정.

전후: TC-1 97 → 100, TC-11 95 → 95(run1) → 100(run2).
