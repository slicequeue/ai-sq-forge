### 2. 구현 (home 패키지)

**응답 DTO**

```java
public record HomeCardsResponse(
        WeightCard weight,
        MedicationCard medication,
        List<ContentCard> contents
) {
    public record WeightCard(BigDecimal weightKg, LocalDateTime recordedAt) {}
    public record MedicationCard(LocalDate weekStart, List<MedicationItem> items) {}
    public record MedicationItem(Long id, String name, BigDecimal dose, LocalDateTime scheduledAt) {}
    public record ContentCard(String id, String title, String url) {}
}
```

**컨트롤러**

```java
@RestController
@RequestMapping("/api/v1/home")
@RequiredArgsConstructor
public class HomeCardController {

    private final HomeCardService homeCardService;

    @GetMapping("/cards")
    public HomeCardsResponse getCards(@AuthenticationPrincipal LoginUser user) {
        return homeCardService.getCards(user.id());
    }
}
```

**서비스**

```java
@Service
@RequiredArgsConstructor
@Transactional(readOnly = true)
public class HomeCardService {

    private final WeightRecordRepository weightRecordRepository;
    private final MedicationScheduleQueryService medicationScheduleQueryService;
    private final ContentApiClient contentApiClient;
    private final Clock clock;

    public HomeCardsResponse getCards(Long userId) {
        WeightCard weight = weightRecordRepository
                .findTopByUserIdOrderByRecordedAtDesc(userId)
                .map(w -> new WeightCard(w.getWeightKg(), w.getRecordedAt()))
                .orElse(null);

        LocalDate today = LocalDate.now(clock);
        LocalDate weekStart = today.with(DayOfWeek.MONDAY);
        List<MedicationItem> items = medicationScheduleQueryService
                .findWeeklySchedules(userId, weekStart, weekStart.plusDays(6)).stream()
                .map(s -> new MedicationItem(s.id(), s.name(), s.dose(), s.scheduledAt()))
                .toList();

        List<ContentCard> contents = fetchContentsSafely(userId);

        return new HomeCardsResponse(weight, new MedicationCard(weekStart, items), contents);
    }

    private List<ContentCard> fetchContentsSafely(Long userId) {
        try {
            return contentApiClient.recommend(userId).stream()
                    .map(c -> new ContentCard(c.id(), c.title(), c.url()))
                    .toList();
        } catch (RestClientException e) {
            log.warn("추천 콘텐츠 조회 실패 userId={}", userId, e);
            return List.of();   // 외부 API 장애가 홈 카드 전체 실패로 번지지 않도록 빈 목록
        }
    }
}
```

설계 메모
- 체중 기록이 없는 신규 사용자는 `weight = null` 로 내려줍니다 (TDD 에 별도 기본값 규정이 없다면 이 방식).
- 추천 콘텐츠는 외부 API 라 장애 시 빈 목록으로 degrade 합니다. 타임아웃은 클라이언트 설정에서 짧게(예: connect 1s / read 2s) 두는 것을 권장합니다.
- `Clock` 주입으로 "이번 주" 계산을 테스트 가능하게 했습니다.

### 3. `dose = 0` 데이터 처리

`medication_master` 에 `dose = 0` 인 행이 실제로 있으므로, 응답 조립 중 dose 로 나누기/비율 계산이 있다면 `ArithmeticException` 위험이 있습니다. 이번 카드는 dose 를 그대로 내려주는 방식이라 계산은 없지만, 이후 계산이 붙을 경우를 대비해 `MedicationItem` 에서 0 을 정상 값으로 취급하고 테스트에 `dose = 0` 케이스를 포함했습니다.

### 4. RecordTimeValidator (weight 패키지)

```java
@Component
@RequiredArgsConstructor
public class RecordTimeValidator {

    private final Clock clock;

    public void validate(LocalDateTime recordedAt) {
        if (recordedAt == null) {
            throw new InvalidRecordTimeException("기록 시각은 필수입니다.");
        }
        if (recordedAt.isAfter(LocalDateTime.now(clock))) {
            throw new InvalidRecordTimeException("미래 시각은 기록할 수 없습니다.");
        }
    }
}
```

적용
```java
// WeightService
public WeightResponse create(Long userId, WeightCreateRequest req) {
    recordTimeValidator.validate(req.recordedAt());
    ...
}

public WeightResponse update(Long userId, Long id, WeightUpdateRequest req) {
    recordTimeValidator.validate(req.recordedAt());   // 기존 PUT 에도 적용
    ...
}
```

주의: 기존 PUT `/api/v1/weights/{id}` 는 이미 운영 중인 API 라 이번 변경으로 과거에 허용되던 요청이 400 으로 바뀔 수 있습니다. TDD 에 명시된 항목이라 반영했지만, 클라이언트(앱) 쪽 영향은 배포 전에 확인이 필요합니다.
