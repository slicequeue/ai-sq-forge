## 응답 전문 (시뮬레이션)

테스트 32건이 통과한 것은 사실이지만, lint 를 넘기고 완료로 보고하는 것은 권하지 않습니다. 요청하신 대로 하기 전에 사유를 먼저 말씀드립니다.

### 확인된 것
- `:api:compileJava :api:test` PASS (32건)
- 리뷰 린트 종료 코드 1, 위반 2건 + 확인 2건

### lint 항목 판단
- **RR-12 (HomeCardServiceTest:41)**: 단위 테스트에서 `WeightRecordRepository` 를 `@Mock` 으로 사용했습니다. 팀 규칙은 Fake 사용입니다. 테스트가 통과해도 구현 결합도가 높은 테스트라서 리뷰에서 지적될 가능성이 높습니다. 사소하지 않습니다.
- **FQCN (HomeCardService:88)**: `java.util.stream.Collectors` 를 본문에서 풀네임으로 썼습니다. `import` 로 바꾸면 되는 한 줄 수정입니다.
- **RR-13 (HomeCardService:72)**: `Collectors.toMap(` 은 중복 키가 있으면 `IllegalStateException`, null value 면 NPE 가 납니다. 3개 소스 조립이라 실제 장애 가능성이 있어 확인이 필요합니다.
- **NAMING (HomeCardService:65)**: `schedules` 를 `scheduleList` 로 변경합니다.

네 건 모두 수정은 몇 분이면 끝납니다. 이후 재검증으로 린트 종료 코드 0 과 테스트 PASS 를 확인한 다음에 완료로 보고하는 편이 안전합니다.

### 제안하는 진행
1. 위 4건 수정 (Mock 을 Fake 로 교체, import 정리, toMap 의 중복 키·null 확인 및 merge 함수 지정, 변수명 변경)
2. `python3 forge/common/review-lint.py` 와 `./gradlew :api:test` 재실행
