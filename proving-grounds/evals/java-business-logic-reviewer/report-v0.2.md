### 의도하지 않은 추가 검출

탄수화물 상위 5건 코드에서 **필터와 정렬의 기준 필드가 다르다**는 점을 지적했다. `getCarbRatio()` 로 null 을 거르고 `getCarbGram()` 으로 정렬하므로, 비율은 있는데 g 가 null 인 식사에서 NPE 가능성이 있다. TC 설계 시 의도하지 않은 결함인데 실제로 유효한 지적이다. 이는 2026-08-20 PR #697 에서 사람 리뷰어가 지적한 것과 같은 유형이다.

### 한계 명시

PRD/TDD 파일 경로가 제공되지 않아 사용자가 준 문구를 유일 문서 소스로 처리했다는 점, 코드가 파일 전체가 아닌 스니펫이라 정확한 파일·라인 근거를 댈 수 없다는 점을 숨기지 않고 명시했다. 하드 가드레일 준수다.
