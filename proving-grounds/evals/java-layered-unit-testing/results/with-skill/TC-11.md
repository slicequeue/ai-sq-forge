## 1. 질문 답변: 조직 컨벤션을 여기도 맞춰야 하나

맞추지 않는다. 조직 컨벤션 적용 여부는 저장소에 `.claude/shared/vc-conventions-guide.md` 가 있는지로 판정하고, 이 저장소(poc-meal-recommender, 조직 밖 개인 PoC)에는 없다. 그래서 규칙 08(테스트 코드 컨벤션)·09(가드레일)만 적용했다. 다른 저장소에서 쓴다는 이유로 이 저장소 코드의 이름·구조를 바꾸지 않았다. 나중에 조직 저장소로 옮기면 그때 다시 판정한다.

## 2. 확인한 것과 가정한 것

확인한 것
- 계층: `application/MealRecommendationQueryService` 는 Application, `infrastructure/MealCandidateJpaRepository` 는 Infrastructure. 근거는 패키지 경로와 의존성(domain 인터페이스 `MealCandidateRepository`, `NutritionScoreCalculator` 를 주입받음)
- 테스트 DB: `src/test/resources/` 가 비어 있어 기존 설정이 없다. 모듈 기존 설정 유지 대상이 없으므로 규칙 09 §1 대로 Testcontainers MySQL 을 쓴다. 운영 DB 가 MySQL 8 이라 H2 는 쓰지 않는다
- Spring Boot 3.2.2: `@ServiceConnection` 사용 가능(3.1 이상)

가정한 것 (실제와 다르면 수정)
- `MealCandidate` 는 `getId()`·`getUserId()` 를 가진다. 테스트에서는 헬퍼 `mealCandidate(id, userId)` 하나로만 생성한다
- `MealRecommendationOutDto` 는 `mealCandidateId()`, `score()` 접근자를 가진 record 다
- `MealCandidateRepository` 는 `findAllByUserId` 하나만 선언한다. 더 있으면 Fake 에 구현을 추가해야 한다
- `MealCandidateJpaEntity` 는 `userId`, `deleted` 를 가진다. 헬퍼 `candidateEntity(userId, deleted)` 에서만 생성한다
- 서비스는 `limit` 이 후보 수보다 크면 전체를 반환한다(요청에 적힌 "limit 개 반환"의 일반적인 해석)

```java
package com.example.meal.domain;

import java.util.ArrayList;
import java.util.List;

// 상태를 가진 저장소라 Fake: 넣어둔 데이터에 사용자 조건을 스스로 적용해 반환한다 (규칙 08 §2-1)
public class FakeMealCandidateRepository implements MealCandidateRepository {

    private final List<MealCandidate> mealCandidateList = new ArrayList<>();

    public MealCandidate save(MealCandidate mealCandidate) {
        mealCandidateList.add(mealCandidate);
        return mealCandidate;
    }

    @Override
    public List<MealCandidate> findAllByUserId(Long userId) {
        return mealCandidateList.stream()
            .filter(mealCandidate -> mealCandidate.getUserId().equals(userId))
            .toList();
    }
}
```

```java
package com.example.meal.domain;

import java.util.HashMap;
import java.util.Map;

// 외부 영양 API 래퍼: 반환값만 중요하므로 Stub (규칙 08 §2-1). 점수를 지정하지 않은 후보는 예외로 실패시켜 0점으로 조용히 통과하지 않게 한다
public class StubNutritionScoreCalculator implements NutritionScoreCalculator {

    private final Map<Long, Integer> scoreByMealCandidateId = new HashMap<>();

    public void setScore(Long mealCandidateId, int score) {
        scoreByMealCandidateId.put(mealCandidateId, score);
    }

    @Override
    public int score(MealCandidate mealCandidate) {
        Integer score = scoreByMealCandidateId.get(mealCandidate.getId());
        if (score == null) {
            throw new IllegalStateException("점수가 지정되지 않은 후보: " + mealCandidate.getId());
        }
        return score;
    }
}
```

### 3-2. Application 테스트

```java
package com.example.meal.application;

import static org.assertj.core.api.Assertions.assertThat;

import com.example.meal.domain.FakeMealCandidateRepository;
import com.example.meal.domain.MealCandidate;
import com.example.meal.domain.StubNutritionScoreCalculator;
import java.util.List;
import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.DisplayName;
import org.junit.jupiter.api.Nested;
import org.junit.jupiter.api.Test;

class MealRecommendationQueryServiceTest {

    private static final Long USER_ID = 1L;
    private static final Long OTHER_USER_ID = 2L;

    private FakeMealCandidateRepository fakeMealCandidateRepository;
    private StubNutritionScoreCalculator stubNutritionScoreCalculator;
    private MealRecommendationQueryService mealRecommendationQueryService;

    @BeforeEach
    void setUp() {
        fakeMealCandidateRepository = new FakeMealCandidateRepository();
        stubNutritionScoreCalculator = new StubNutritionScoreCalculator();
        mealRecommendationQueryService =
            new MealRecommendationQueryService(fakeMealCandidateRepository, stubNutritionScoreCalculator);
    }

    @Nested
    @DisplayName("recommend")
    class Recommend {

        @Test
        @DisplayName("후보가 limit 보다 많으면 점수 내림차순 상위 limit 개만 반환한다")
        void recommend_moreCandidatesThanLimit_returnsTopLimitByScoreDescending() {
            // Given: 입력 순서와 점수 순서가 일치하지 않고, limit(3) 을 넘는 5건
            givenCandidateWithScore(10L, USER_ID, 40);
            givenCandidateWithScore(11L, USER_ID, 90);
            givenCandidateWithScore(12L, USER_ID, 10);
            givenCandidateWithScore(13L, USER_ID, 70);
            givenCandidateWithScore(14L, USER_ID, 55);

            // When
            List<MealRecommendationOutDto> mealRecommendationOutDtoList =
                mealRecommendationQueryService.recommend(USER_ID, 3);

            // Then
            assertThat(mealRecommendationOutDtoList)
                .extracting(MealRecommendationOutDto::mealCandidateId)
                .containsExactly(11L, 13L, 14L);
            assertThat(mealRecommendationOutDtoList)
                .extracting(MealRecommendationOutDto::score)
                .containsExactly(90, 70, 55);
        }

        @Test
        @DisplayName("후보가 limit 보다 적으면 전체를 점수 내림차순으로 반환한다")
        void recommend_fewerCandidatesThanLimit_returnsAllByScoreDescending() {
            // Given
            givenCandidateWithScore(10L, USER_ID, 20);
            givenCandidateWithScore(11L, USER_ID, 80);

            // When
            List<MealRecommendationOutDto> mealRecommendationOutDtoList =
                mealRecommendationQueryService.recommend(USER_ID, 5);

            // Then
            assertThat(mealRecommendationOutDtoList)
                .extracting(MealRecommendationOutDto::mealCandidateId)
                .containsExactly(11L, 10L);
        }

        @Test
        @DisplayName("다른 사용자의 후보는 점수가 더 높아도 포함하지 않는다")
        void recommend_otherUserCandidateWithHigherScore_excludesIt() {
            // Given
            givenCandidateWithScore(10L, USER_ID, 30);
            givenCandidateWithScore(20L, OTHER_USER_ID, 99);

            // When
            List<MealRecommendationOutDto> mealRecommendationOutDtoList =
                mealRecommendationQueryService.recommend(USER_ID, 5);

            // Then
            assertThat(mealRecommendationOutDtoList)
                .extracting(MealRecommendationOutDto::mealCandidateId)
                .containsExactly(10L);
        }

        @Test
        @DisplayName("후보가 하나도 없으면 빈 목록을 반환한다")
        void recommend_noCandidates_returnsEmptyList() {
            // Given: 저장된 후보 없음

            // When
            List<MealRecommendationOutDto> mealRecommendationOutDtoList =
                mealRecommendationQueryService.recommend(USER_ID, 5);

            // Then
            assertThat(mealRecommendationOutDtoList).isEmpty();
        }
    }

    private void givenCandidateWithScore(Long mealCandidateId, Long userId, int score) {
        fakeMealCandidateRepository.save(mealCandidate(mealCandidateId, userId));
        stubNutritionScoreCalculator.setScore(mealCandidateId, score);
    }

    // 가정: MealCandidate 생성 방식은 실제 도메인에 맞게 이 헬퍼 한 곳만 고친다
    private MealCandidate mealCandidate(Long mealCandidateId, Long userId) {
        return MealCandidate.of(mealCandidateId, userId, "닭가슴살 샐러드");
    }
}
```

### 3-3. Infrastructure 테스트 (@DataJpaTest + Testcontainers MySQL)

```java
package com.example.meal.infrastructure;

import static org.assertj.core.api.Assertions.assertThat;

import java.util.List;
import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.DisplayName;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.autoconfigure.jdbc.AutoConfigureTestDatabase;
import org.springframework.boot.test.autoconfigure.orm.jpa.DataJpaTest;
import org.springframework.boot.test.autoconfigure.orm.jpa.TestEntityManager;
import org.springframework.boot.testcontainers.service.connection.ServiceConnection;
import org.testcontainers.containers.MySQLContainer;
import org.testcontainers.junit.jupiter.Container;
import org.testcontainers.junit.jupiter.Testcontainers;

@DataJpaTest(properties = "spring.jpa.hibernate.ddl-auto=create-drop")
@AutoConfigureTestDatabase(replace = AutoConfigureTestDatabase.Replace.NONE) // 내장 DB 로 바꿔치기 금지 (규칙 09 §1)
@Testcontainers
class MealCandidateJpaRepositoryTest {

    private static final Long USER_ID = 1L;
    private static final Long OTHER_USER_ID = 2L;

    @Container
    @ServiceConnection
    static final MySQLContainer<?> MYSQL = new MySQLContainer<>("mysql:8.0");

    private MealCandidateJpaRepository mealCandidateJpaRepository;
    private TestEntityManager testEntityManager;

    @BeforeEach
    void setUp(@Autowired MealCandidateJpaRepository mealCandidateJpaRepository,
               @Autowired TestEntityManager testEntityManager) {
        this.mealCandidateJpaRepository = mealCandidateJpaRepository;
        this.testEntityManager = testEntityManager;
    }

    @Test
    @DisplayName("삭제되지 않은 해당 사용자의 후보만 조회한다")
    void findAllByUserIdAndDeletedFalse_mixedRows_returnsOnlyActiveRowsOfUser() {
        // Given
        MealCandidateJpaEntity activeEntity = testEntityManager.persist(candidateEntity(USER_ID, false));
        testEntityManager.persist(candidateEntity(USER_ID, true));
        testEntityManager.persist(candidateEntity(OTHER_USER_ID, false));
        testEntityManager.flush();
        testEntityManager.clear();

        // When
        List<MealCandidateJpaEntity> mealCandidateJpaEntityList =
            mealCandidateJpaRepository.findAllByUserIdAndDeletedFalse(USER_ID);

        // Then
        assertThat(mealCandidateJpaEntityList)
            .extracting(MealCandidateJpaEntity::getId)
            .containsExactly(activeEntity.getId());
    }

    @Test
    @DisplayName("사용자의 후보가 모두 삭제되었으면 빈 목록을 반환한다")
    void findAllByUserIdAndDeletedFalse_allDeleted_returnsEmptyList() {
        // Given
        testEntityManager.persist(candidateEntity(USER_ID, true));
        testEntityManager.persist(candidateEntity(USER_ID, true));
        testEntityManager.flush();
        testEntityManager.clear();

        // When
        List<MealCandidateJpaEntity> mealCandidateJpaEntityList =
            mealCandidateJpaRepository.findAllByUserIdAndDeletedFalse(USER_ID);

        // Then
        assertThat(mealCandidateJpaEntityList).isEmpty();
    }

    @Test
    @DisplayName("후보가 없는 사용자는 빈 목록을 반환한다")
    void findAllByUserIdAndDeletedFalse_noRowsForUser_returnsEmptyList() {
        // Given
        testEntityManager.persist(candidateEntity(OTHER_USER_ID, false));
        testEntityManager.flush();
        testEntityManager.clear();

        // When
        List<MealCandidateJpaEntity> mealCandidateJpaEntityList =
            mealCandidateJpaRepository.findAllByUserIdAndDeletedFalse(USER_ID);

        // Then
        assertThat(mealCandidateJpaEntityList).isEmpty();
    }

    // 가정: 엔티티 생성 방식은 실제 엔티티에 맞게 이 헬퍼 한 곳만 고친다
    private MealCandidateJpaEntity candidateEntity(Long userId, boolean deleted) {
        return MealCandidateJpaEntity.builder()
            .userId(userId)
            .name("닭가슴살 샐러드")
            .deleted(deleted)
            .build();
    }
}
```

## 4. 필요한 테스트 설정

`src/test/resources/` 에 파일을 만들지 않는다. 컨테이너 접속 정보는 `@ServiceConnection` 이 주입하고, 스키마는 `@DataJpaTest(properties = ...)` 의 `create-drop` 으로 만든다. 이 저장소가 Flyway 를 쓰면 `create-drop` 대신 마이그레이션을 적용하도록 바꿔야 한다(미확인). 필요한 것은 `build.gradle` 의존성 추가뿐이다. 버전은 Spring Boot 3.2.2 BOM 이 관리한다.

```groovy
dependencies {
    testImplementation 'org.springframework.boot:spring-boot-starter-test'
    testImplementation 'org.springframework.boot:spring-boot-testcontainers'
    testImplementation 'org.testcontainers:junit-jupiter'
    testImplementation 'org.testcontainers:mysql'
}
```

`MealCandidateJpaEntity` 의 패키지가 `@DataJpaTest` 의 기본 스캔 범위(`@SpringBootApplication` 클래스의 하위 패키지) 밖이면 `@AutoConfigurationPackage` 나 `@EntityScan` 이 필요하다(미확인).

Testcontainers 는 Docker 가 실행 중이어야 한다. "Docker 없이 돌게 H2 로 바꾸기"는 규칙 09 §1 에서 금지한 변경이라 하지 않았다.
