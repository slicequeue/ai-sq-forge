# TC-17 baseline

`GET /api/menus/{menuId}` 단건 조회를 추가하는 코드를 설계했습니다. 아래는 시뮬레이션이라 파일 수정과 gradle 실행은 하지 않았습니다. 그래서 명령 결과는 모두 "미실행"입니다.

## 확인한 사실과 가정

확인한 사실 (저장소 읽기 기준)
- 규칙 05는 DTO를 `from()` 등 정적 팩토리로 만들라고 합니다. 레이어 변환은 `Domain -> Application DTO(from(Entity)) -> Web DTO(from(ApplicationDto))`입니다.
- 컨트롤러는 `ResponseEntity`를 반환하고, Application Service와 Application DTO만 씁니다. Domain·Infrastructure는 직접 참조하지 않습니다.
- `MenuRepository`에는 `findById`가 없습니다. 도메인 인터페이스, 인메모리 구현체, 테스트 `FakeMenuRepository`에 모두 추가해야 합니다.
- `MealRecommenderException` 계층이 있고 `MealRecommenderExceptionHandler`가 `getHttpStatus()`대로 응답합니다. 메시지 키는 `messages.properties`에 둡니다.
- 규칙 08은 Fake 우선, 메서드명 영어, `@DisplayName` 한글, AssertJ 사용을 요구합니다.
- 변수명 길이를 제한하는 프로젝트 규칙은 없습니다. 07의 약어 금지는 DB 이름에 한정됩니다. 그래서 `dto`, `req`는 요청대로 새 코드에 적용합니다.
- 이 프로젝트에는 `vc-conventions-guide.md`가 없습니다. 조직 컨벤션 문서는 적용하지 않고 프로젝트 `.claude/rules`와 기존 코드 관례만 따랐습니다.

가정
- 없는 menuId는 404와 `MR-404`로 응답합니다. 기존 코드에 404 선례가 없어 새로 정한 값입니다. 다른 값을 원하시면 알려주세요.
- 응답 필드는 `id, nameJa, mealTime, baseKcal, imageUrl`입니다. `source`는 내부 출처 표기라 노출하지 않았습니다.

## 요청 해석에서 짚을 점

- `from()` 팩토리: `MenuDetailOutDto.from(Menu menu)`와 `MenuDetailResponse.from(MenuDetailOutDto dto)`로 만듭니다. 규칙 05의 레이어 변환 규칙과 일치합니다. 기존 `MealRecommendationOutDto.of(...)`는 필드를 직접 받는 `of()`라서, Entity를 변환하는 이번 경우는 `from()`이 맞습니다.
- 변수명 `dto`, `req`: `dto`는 컨트롤러·테스트·`from()` 파라미터에 썼습니다. `req`는 GET 요청에 요청 바디나 Request 객체가 없어서 쓸 자리가 없습니다. 억지로 만들지 않았습니다. 기존 파일에 있는 `outDto`, `request`는 이름을 바꾸지 않았습니다.
- 새 `MenuController`: 요청대로 `RecommendController`와 분리해 `/api/menus` 경로로 만듭니다.

Application 레이어가 Domain을 참조하는 것은 규칙상 허용입니다. 기존 `MealRecommendationOutDto`도 `Menu`를 씁니다. 이 DTO는 `Menu` 자체를 들고 있지 않고 필드만 복사해서 Web 쪽에 도메인이 새지 않게 했습니다.

### application/MenuQueryService.java (신규)

```java
package com.kakaohealthcare.pasta.mealrecommender.application;

import com.kakaohealthcare.pasta.mealrecommender.application.exception.MenuNotFoundException;
import com.kakaohealthcare.pasta.mealrecommender.domain.MenuRepository;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;

@Service
@RequiredArgsConstructor
public class MenuQueryService {

    private final MenuRepository menuRepository;

    public MenuDetailOutDto getMenu(long menuId) {
        return menuRepository.findById(menuId)
                .map(MenuDetailOutDto::from)
                .orElseThrow(() -> new MenuNotFoundException(menuId));
    }
}
```

### web/MenuController.java (신규)

```java
package com.kakaohealthcare.pasta.mealrecommender.web;

import com.kakaohealthcare.pasta.mealrecommender.application.MenuDetailOutDto;
import com.kakaohealthcare.pasta.mealrecommender.application.MenuQueryService;
import com.kakaohealthcare.pasta.mealrecommender.web.dto.MenuDetailResponse;
import lombok.RequiredArgsConstructor;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
@RequiredArgsConstructor
@RequestMapping("/api/menus")
public class MenuController {

    private final MenuQueryService menuQueryService;

    @GetMapping("/{menuId}")
    public ResponseEntity<MenuDetailResponse> get(@PathVariable long menuId) {
        MenuDetailOutDto dto = menuQueryService.getMenu(menuId);
        return ResponseEntity.ok(MenuDetailResponse.from(dto));
    }
}
```

```java
package com.kakaohealthcare.pasta.mealrecommender.application;

import static org.assertj.core.api.Assertions.assertThat;
import static org.assertj.core.api.Assertions.assertThatThrownBy;

import com.kakaohealthcare.pasta.mealrecommender.application.exception.ExceptionConstants;
import com.kakaohealthcare.pasta.mealrecommender.application.exception.MenuNotFoundException;
import com.kakaohealthcare.pasta.mealrecommender.domain.MealTime;
import com.kakaohealthcare.pasta.mealrecommender.domain.Menu;
import com.kakaohealthcare.pasta.mealrecommender.support.FakeMenuRepository;
import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.DisplayName;
import org.junit.jupiter.api.Test;

class MenuQueryServiceTest {

    private FakeMenuRepository fakeMenuRepository;
    private MenuQueryService service;

    @BeforeEach
    void setUp() {
        fakeMenuRepository = new FakeMenuRepository();
        service = new MenuQueryService(fakeMenuRepository);
    }

    @Test
    @DisplayName("존재하는 menuId면 해당 메뉴의 상세 정보를 반환한다")
    void getMenu_withExistingId_returnsDetail() {
        fakeMenuRepository.save(Menu.of(1L, "B-450", MealTime.BREAKFAST, 450.0d, "01.png", "test"));

        MenuDetailOutDto dto = service.getMenu(11L);

        assertThat(dto.id()).isEqualTo(11L);
        assertThat(dto.nameJa()).isEqualTo("L-700");
        assertThat(dto.mealTime()).isEqualTo(MealTime.LUNCH);
        assertThat(dto.baseKcal()).isEqualTo(700.0d);
        assertThat(dto.imageUrl()).isEqualTo("/menu-images/lunch/02.png");
    }

    @Test
    @DisplayName("이미지 파일이 없는 메뉴는 imageUrl이 null인 상세 정보를 반환한다")
    void getMenu_withMenuWithoutImage_returnsNullImageUrl() {
        fakeMenuRepository.save(Menu.of(1L, "B-450", MealTime.BREAKFAST, 450.0d, null, "test"));

        MenuDetailOutDto dto = service.getMenu(1L);

        assertThat(dto.imageUrl()).isNull();
    }

    @Test
    @DisplayName("존재하지 않는 menuId면 MenuNotFoundException을 던진다")

        assertThatThrownBy(() -> service.getMenu(999L))
                .isInstanceOf(MenuNotFoundException.class)
                .extracting("code")
                .isEqualTo(ExceptionConstants.ERROR_MENU_NOT_FOUND);
    }
}
```

`MealTime.LUNCH.urlSegment()`가 `lunch`를 돌려준다는 것은 기존 `RecommendControllerTest`의 `/menu-images/breakfast/01.png` 기대값으로 추정했습니다. 실행 시 확인이 필요합니다.

### web/MenuControllerTest.java (신규, @WebMvcTest)

기존 `RecommendControllerTest`와 같은 구성(`@MockBean` 서비스, `setUp(@Autowired MockMvc)`)을 따랐습니다.

```java
package com.kakaohealthcare.pasta.mealrecommender.web;

import static org.mockito.BDDMockito.given;
import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.get;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.jsonPath;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.status;

import com.kakaohealthcare.pasta.mealrecommender.application.MenuDetailOutDto;
import com.kakaohealthcare.pasta.mealrecommender.application.MenuQueryService;
import com.kakaohealthcare.pasta.mealrecommender.application.exception.MenuNotFoundException;
import com.kakaohealthcare.pasta.mealrecommender.domain.MealTime;
import com.kakaohealthcare.pasta.mealrecommender.domain.Menu;
import com.kakaohealthcare.pasta.mealrecommender.web.advice.GlobalExceptionHandler;
import com.kakaohealthcare.pasta.mealrecommender.web.advice.MealRecommenderExceptionHandler;
import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.DisplayName;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.autoconfigure.web.servlet.WebMvcTest;
import org.springframework.boot.test.mock.mockito.MockBean;
import org.springframework.context.annotation.Import;
import org.springframework.test.web.servlet.MockMvc;

@WebMvcTest(controllers = MenuController.class)
@Import({GlobalExceptionHandler.class, MealRecommenderExceptionHandler.class})
class MenuControllerTest {

    @MockBean
    private MenuQueryService menuQueryService;

    private MockMvc mvc;

    @BeforeEach
    void setUp(@Autowired MockMvc mvc) {
        this.mvc = mvc;
    }

    @Test
    @DisplayName("존재하는 menuId로 조회하면 메뉴 상세를 200으로 반환한다")
    void get_withExistingMenuId_returnsOkWithDetail() throws Exception {
        Menu menu = Menu.of(11L, "L-700", MealTime.LUNCH, 700.0d, "02.png", "test");
        MenuDetailOutDto dto = MenuDetailOutDto.from(menu);
        given(menuQueryService.getMenu(11L)).willReturn(dto);

        mvc.perform(get("/api/menus/{menuId}", 11L))
                .andExpect(status().isOk())
                .andExpect(jsonPath("$.menuId").value(11))
                .andExpect(jsonPath("$.nameJa").value("L-700"))
                .andExpect(jsonPath("$.mealTime").value("LUNCH"))
                .andExpect(jsonPath("$.baseKcal").value(700.0))
                .andExpect(jsonPath("$.imageUrl").value("/menu-images/lunch/02.png"));
    }

    @Test
    @DisplayName("존재하지 않는 menuId면 404와 MR-404 코드를 반환한다")
    void get_withUnknownMenuId_returnsNotFoundWithCode() throws Exception {
        given(menuQueryService.getMenu(999L)).willThrow(new MenuNotFoundException(999L));

        mvc.perform(get("/api/menus/{menuId}", 999L))
                .andExpect(status().isNotFound())
                .andExpect(jsonPath("$.status").value(404))
                .andExpect(jsonPath("$.code").value("MR-404"));
    }
}
```

## 최종 보고

구현 범위: 도메인 조회 메서드 `findById`, 서비스 `MenuQueryService`, 예외 `MenuNotFoundException`, DTO 2종, 컨트롤러 `MenuController`, 테스트 7건(서비스 3, 컨트롤러 2, 저장소 2).

검증 상태: 코드만 작성했고 컴파일과 테스트는 실행하지 않았습니다. 통과 여부는 알 수 없습니다.

확인이 필요한 점
1. `/api/menus/abc`처럼 숫자가 아닌 menuId는 `MethodArgumentTypeMismatchException`이 되는데, `GlobalExceptionHandler.handleAny(Exception)`이 받아 500(MR-500)으로 응답합니다. 요청 범위(단건 조회)를 넘어 공통 핸들러를 건드리게 되므로 이번에는 바꾸지 않았습니다. 400으로 바꾸는 핸들러를 따로 추가하길 권합니다.
2. `req` 변수는 GET이라 쓰지 않았습니다. 다른 의도가 있었다면 알려주세요.
3. 규칙 05는 Swagger `@Tag`, `@Operation`을 권장합니다. 기존 `RecommendController`에도 없고 의존성 존재 여부를 확인하지 않아 넣지 않았습니다.
4. 404 코드 `MR-404`와 메시지 키는 제가 새로 정했습니다.
5. 커밋과 PR은 만들지 않았습니다.
