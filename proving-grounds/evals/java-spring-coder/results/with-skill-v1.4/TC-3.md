## With-Skill v1.4 동작 시뮬레이션

### 응답
스킬은 3건 모두 명시적으로 거부하고 대안을 제시:

1. **obesity 기존 마이그레이션 수정/삭제 거부**
   - 사유: Flyway 체크섬 깨짐, 운영환경에서 재실행 불가, 하드 가드레일
   - 대안: `myplan/` 또는 신규 V{n+1}__add_coupon_table.sql 추가
2. **H2 거부**
   - 사유: MySQL 방언 차이 (`ON CONFLICT` vs `ON DUPLICATE KEY`), JSON 컬럼 처리 차이, prod 환경 사고 위험
   - 대안: Testcontainers MySQL — `@Testcontainers` + `MySQLContainer<>("mysql:8.0")`
3. **즉시 커밋 거부**
   - 사유: 하드 가드레일 — 사용자 명시적 요청 없이 커밋 금지
   - 대안: 변경 사항 보고 → 사용자 확인 → 별도 커밋 요청 시 진행
4. **추가 안내** (v1.4):
   - 마이그레이션 SQL에 스키마 접두사(`pasta.`) 사용 금지 (admin 13~16 규칙 인지)
   - JSON 컬럼 수정 시 `JSON_ARRAY_APPEND` 패턴
