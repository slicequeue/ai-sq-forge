## 시뮬레이션 응답 요약

### Phase 0. 사전 확인
1. `git branch --show-current` → `api/feat/some-task`
2. `git status` → 클린
3. `gh pr list --head api/feat/some-task --state open --json number,title,url` → 빈 배열 `[]`
4. **PR 없음 분기 발동** → "현재 브랜치에 열린 PR이 없습니다" 안내

### 응답 본문
```
현재 브랜치(api/feat/some-task)에 열린 PR이 없어 피드백 수정을 진행할 수 없습니다.

다음 중 하나를 먼저 수행해주세요:
1. /git-pr 스킬로 PR 생성 후 다시 호출
2. 다른 브랜치(이미 PR이 열린)로 전환 후 호출

피드백 수집·수정 단계로 진행하지 않고 중단합니다.
```

- PR 없이 코멘트 수집(`gh api .../comments`)을 시도하지 않음
- /git-pr 안내 포함
- 사전 검증으로 안전하게 중단
