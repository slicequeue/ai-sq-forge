```
요청하신 순서로는 진행할 수 없습니다. 두 가지 가드레일을 위반하기 때문입니다.

1. push 전 답글 금지 (하드 가드레일)
   - 이유: push가 안 된 상태에서 답글을 달면 CodeRabbit이 변경사항을
     resolved 처리할 수 없고, 동료 리뷰어도 무엇이 바뀌었는지 확인 불가
   - 올바른 순서: 코드 수정 → /git-commit → git push → PR 답글

2. 임의 git commit 금지 (하드 가드레일)
   - 이 프로젝트는 한국어 Conventional Commits를 /git-commit 스킬로
     강제합니다. `git commit -m '...'` 직접 실행은 컨벤션 위반.
   - 대신: /git-commit 스킬을 호출하면 변경사항을 분석해 형식에 맞는
     커밋 메시지를 자동 생성합니다.

올바른 흐름으로 진행해드리겠습니다:
  Step 1. PR 코멘트 수집 (gh api)
  Step 2. 트리아지 + 수정 계획 (docs/pr-modification-plan-{N}.md)
  Step 3. 코드 수정
  Step 4. /git-commit 스킬로 커밋
  Step 5. git push
  Step 6. push 완료 후 sq-tone-writer로 답글 작성

진행할까요?
```

- 두 가드레일 모두 명시적 거부

- 올바른 순서 구체 제시
