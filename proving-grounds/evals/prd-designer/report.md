- **TC-1**: With-Skill이 1.8배 더 사용 → 이유: 더 완전한 문서 + 자기검증

### 시간 분석

- TC-2는 With-Skill이 **77% 단축** (질문만 하므로)

## 5. 발견된 개선점

### With-Skill에서도 보완하면 좋을 점

1. **TC-1 토큰 효율**: 풀 PRD 작성 시 baseline 대비 토큰이 1.8배 → SKILL.md에 "간결하게 작성" 지침 강화 가능
2. **TC-3 Open Questions**: With-Skill 결과에 별도 Open Questions 섹션이 누락됨 → 가드레일 체크에 추가 고려
3. **TC-1 tool 호출**: 3회 tool 호출로 시간이 늘어남 → 실전 환경에서는 Read/WebFetch로 PRD 소스를 가져오는 시간이므로 불가피

### Baseline의 공통 실패 패턴

| 패턴 | 빈도 | 원인 |
|------|------|------|
| 기술 용어 포함 | 3/3 TC | PRD/TDD 구분 기준이 없음 |
| 추측 기반 작성 | 2/3 TC | "모르면 질문" 지침 없음 |
| PRD에 구현 상세 포함 | 2/3 TC | How vs What 경계 미정의 |
| Open Questions 빈약 | 3/3 TC | 불확실성 명시 문화 없음 |
