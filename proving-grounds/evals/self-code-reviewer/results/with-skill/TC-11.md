### 실패·회귀 한 줄 답 (RR-13·RR-12)

- **실패 시 사용자가 보는 것**
  - 일정 조회가 실패하면 마지막 기록이 있어도 카드가 NO_RECORD 로 나옵니다. 기록이 있는데 "기록 없음"이라는 틀린 상태입니다.
  - 일정이 없는 정상 케이스(`PlanNotFoundException`)에서도 똑같이 NO_RECORD 가 나옵니다.
  - 일정 조회 예외가 같은 트랜잭션을 rollback-only 로 만들면 catch 해도 커밋 시점에 `UnexpectedRollbackException` 이 나서 홈 카드 API 가 500 이 됩니다. 이 경우 `empty()` 도 내려가지 않습니다.
  - 브랜드 마스터에 `max_dose_mg` 가 null 인 행이 한 건만 있어도 `toMap` 에서 NPE 가 나, 이 메서드를 쓰는 홈 피드 전체가 500 입니다.
  - 푸시 예약이 n번째에서 실패하면 앞 n-1건은 외부에 예약됐는데 DB 의 reservationId 는 전부 롤백됩니다. 사용자는 푸시를 받지만 서버는 그 예약을 취소할 수 없습니다.
- **깨뜨리면 실패할 테스트**: 전달된 변경에 테스트가 없어서 지목할 수 있는 기존 테스트가 없습니다. 이 상태로 try 범위나 `rollbackFor` 를 바꿔도 아무것도 실패하지 않습니다. 아래 "필수 테스트"를 추가해야 합니다.
