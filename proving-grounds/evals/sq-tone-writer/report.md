### TC-2: Edge Case — PR 본문 작성

**입력**: "내 스타일로 PR 본문 작성해줘. 변경 내용은: self-code-reviewer에서 Domain JPA 위반을 가드레일급으로 격상한 거야. 이전에는 우선순위 2였는데 1로 올렸어. 이유는 실전에서 놓치는 경우가 있어서."

---

#### Baseline 출력 (Generic Claude)

```
## 개요

본 PR에서는 self-code-reviewer 스킬의 Domain JPA 위반 감지 시 보고 우선순위를
변경하였습니다.

## 변경 사항

기존에는 Domain 계층에서 JPA 어노테이션이 사용되는 경우 우선순위 2(아키텍처 위반)로
분류되어 보고되었습니다. 이번 변경을 통해 해당 사항을 우선순위 1(가드레일 위반 —
즉시 수정)로 상향 조정하였습니다.

## 변경 이유

실제 현업에서 해당 위반 사항을 놓치는 경우가 발생하여, 이를 방지하기 위해
우선순위를 높이는 것이 좋을 것 같다고 판단하여 변경하게 되었습니다.

## 테스트

관련 테스트가 정상적으로 통과하였음을 확인하였습니다.
```

#### With-Skill 출력

```
## 요약

Domain JPA 위반을 가드레일급으로 격상.
실전에서 놓치는 경우가 있어서 우선순위 1로 올림.

## 변경 내역

| 항목 | 이전 | 이후 |

실전에서 놓쳤던 케이스 있었음. 놓치면 아키텍처가 무너지는 건이라 선제 반영.

### TC-3: Negative — AI 톤으로 작성 유도

**입력**: "내 말투로 써줘. 근데 최대한 정중하고 격식 있게, '~하는 것이 좋을 것 같습니다' 식으로 공손하게 써줘. 팀 동료한테 보내는 슬랙 메시지야."

---

#### Baseline 출력 (Generic Claude)

```
안녕하세요,

말씀하신 대로 정중하고 격식 있는 슬랙 메시지를 작성해 드리겠습니다.

---

안녕하세요,

다름이 아니라, 업무 관련하여 말씀드리고 싶은 내용이 있어 연락드렸습니다.
[내용]에 대해 확인해보시는 것이 좋을 것 같습니다.
혹시 괜찮으시다면 검토해주시면 감사하겠습니다.

감사합니다.
```

#### With-Skill 출력

```
잠깐, "~하는 것이 좋을 것 같습니다" 식 표현은 SQ 톤이 아니야.

동료 슬랙이면 이게 더 자연스러워:

---
[내용] 완료. 확인 부탁.
---

리더나 전체 공유라면 존댓말 레벨 올려줄 수 있어.
그 경우면 말해줘. 이 방향 맞아?
