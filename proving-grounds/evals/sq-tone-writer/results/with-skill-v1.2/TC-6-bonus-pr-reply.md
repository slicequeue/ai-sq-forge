# TC-6 v1.2 보너스 — PR 리뷰어 답글 (신규 섹션 정합성 확인)

**버전**: v1.2
**유형**: 신규 섹션 정합성 확인용 (테스트 케이스 미정의 — 보너스 검증)

## 입력 (가상 시나리오)
```
"내 말투로 PR 리뷰 답글 써줘. 리뷰어가 @Transactional 무효라고 지적했고,
나는 그거 제거하고 Javadoc 에 사유 남겼어.
근데 이 서비스는 빈 등록하면 OAuth2 자동설정 영향으로 구글 OIDC 로그인이 깨져서
new 로 둘 수밖에 없었던 배경이 있어. 추후 api 모듈 OAuth2AuthorizedClientService
참고해서 빈 등록 시도해볼 거야."
```

## With-Skill v1.2 시뮬레이션 출력
```
매체: GitHub PR 답글 / 수신자: 리뷰어 (시니어)

---

@리뷰어 우선 @Transactional 제거하고 사유 Javadoc 에 남겼습니다.

이 서비스 Spring 빈으로 등록하면 OAuth2 자동설정 부분 영향으로 구글 OIDC 로그인에 문제가 있었습니다... 이 부분 때문에 로그인 자체가 안 되는 이슈가 있었습니다. 그래서 불가피하게 빈이 아닌 new 로 생성하는 구조로 둔 상태입니다.

api 모듈 OAuth2AuthorizedClientService 구현 참고해서 추후 빈 등록하면서도 로그인 영향 없게 만들 수 있는지 시도해볼 예정입니다. 관련 우려사항은 Javadoc 에 주석으로 달아뒀습니다!

---

톤 체크: AI 표현 0건 / 반말 0건 / 이모지(`!`) 1회 — 답글 전용 허용
이 느낌 맞아?
```
