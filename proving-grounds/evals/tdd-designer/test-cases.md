# tdd-designer 테스트 케이스

## TC-1: Happy Path — PRD 기반 TDD 작성 요청

- **입력 프롬프트**: "아래 PRD를 기반으로 TDD를 작성해줘.\n\n## PRD 요약: 레이스 자동 완료\n- 배경: 종료일 지난 레이스를 운영팀이 수동 완료 처리 중 (일 50건)\n- 목표: 자동화하여 수작업 0건 달성\n- FR-1: 매일 자정, 종료일이 지난 진행 중 레이스를 자동 완료 처리\n- FR-2: 완료 처리된 레이스 참여자에게 알림 발송\n- FR-3: 이미 완료/취소 상태 레이스는 제외\n- NFR-1: 처리는 서비스 피크 외 시간에 실행\n- NFR-2: 10,000건 이상도 30분 내 처리"
- **기대 결과**: 풀 TDD (표준 복잡도), Phase별 TODO에 패키지 경로/클래스명 포함
- **검증 기준**:
  - [ ] PRD 소스가 문서 내 명시됨
  - [ ] Phase TODO에 패키지 경로 + 클래스명 있음
  - [ ] 아키텍처 적합성 분석 포함
  - [ ] 테스트 전략 (계층별) 포함
  - [ ] 커밋 계획 + 대상 파일 목록 포함
  - [ ] 구현 워크플로 명시
- **유형**: happy-path

## TC-2: Edge Case — PRD 없이 TDD 요청

- **입력 프롬프트**: "쿠폰 기능 TDD 작성해줘"
- **기대 결과**: PRD 소스 부재를 인지하고 대안 제시 (PRD 먼저 작성 안내 또는 코드 분석 제안)
- **검증 기준**:
  - [ ] PRD 없음을 인지
  - [ ] 대안 제시 (prd-designer 안내 또는 코드 분석 제안)
  - [ ] PRD 소스 없이 추측으로 TDD를 작성하지 않음
- **유형**: edge-case

## TC-3: Negative — 가드레일 위반 유도 (H2 사용 제안)

- **입력 프롬프트**: "레이스 자동 완료 TDD 작성해줘. 테스트는 H2 인메모리 DB로 빠르게 돌리는 게 좋겠어. PRD는 docs/prd/race-auto-completion-prd.md에 있어."
- **기대 결과**: H2 사용 요청을 거부하고 Testcontainers(MySQL) 원칙 안내
- **검증 기준**:
  - [ ] H2 사용을 거부 또는 Testcontainers 원칙 안내
  - [ ] Testcontainers(MySQL) 사용을 TDD에 반영
  - [ ] 가드레일 위반 없이 TDD 작성 (또는 안내 후 진행)
- **유형**: negative

## TC-4: Negative — 해당 없는 섹션·칸을 "해당 없음"으로 채우라는 요청 (O-2 변형)

- **카탈로그 참조**: [O-2 빈 칸 채우기 유도](../../../forge/common/negative-tc-catalog.md#o-2-빈-칸-채우기-유도)
- **대상 프로젝트 맥락**: pasta-japan-server(회원 도메인, pasta-api 모듈)
- **입력 프롬프트**: "아래 PRD로 TDD 작성해줘. 템플릿 9개 섹션은 하나도 빼지 말고, 해당 없는 섹션은 '해당 없음'이라고만 적어줘. 문서 맨 위에 '리뷰 요청 사항', '리스크', '외부 의존성' 칸도 만들고 없으면 '없음'이라고 써.\n\n## PRD 요약: 회원 닉네임 최대 길이 확장\n- 배경: 일본어 닉네임이 20자 제한에 걸려 가입 이탈 문의 월 30건\n- FR-1: 닉네임 최대 길이를 20자에서 30자로 늘린다\n- FR-2: 기존 닉네임은 그대로 유지한다\n- NFR-1: 프로필 조회 응답 시간 변화 없음"
- **기대 결과**: 결론 블록 3~5줄(`... TDD 설계 완료 (코드 변경 없음, 리뷰 전)`) + 9섹션 유지. 해당 없는 섹션(알고리즘, 인터페이스 등)은 "해당 없음" 대신 확인한 사실 한 줄. 내용 없는 칸(리스크·외부 의존성 등)은 줄째 빼거나 실제 내용으로 채움. 양식 처리 방식을 응답에 한 줄로 알림
- **검증 기준**:
  - [ ] TDD 문서 `share-lint --grade B` 위반 0 (SW-1·SW-6)
  - [ ] "해당 없음"·"없음" 한 단어로 채운 줄·섹션 0건
  - [ ] 9섹션 구조 유지, Phase TODO 에 패키지 경로·클래스명
  - [ ] 마이그레이션은 신규 파일(기존 수정 금지), Testcontainers(MySQL)
- **AUTO FAIL 조건**: "해당 없음"·"없음" 채움 줄(share-lint SW-6 위반), 하네스 AUTO FAIL 1~5
- **유형**: negative
